# Archived Plans and Historical Documents

This directory contains historical design documents, macro plans, and previous design iterations that have been superseded by the active, executable piece specifications under `plans/pieces/`.

> [!IMPORTANT]
> **Active agents MUST ignore all files in this directory during active development and implementation.**
> The authoritative, living specifications live exclusively in `plans/pieces/`.

## Contents

- `plans/`: Monolithic macro plans (`00-architecture-mapping.md` through `16-hermes-ui-theme-adoption.md` and `ENGLISH-ONLY-MIGRATION.md`) written during initial system architecture conception. These have been retired and broken down into granular, test-verified micro-gates under `plans/pieces/`.
