## Summary

Registers the `/kanban` operator slash command into the host commands registry (`ctx.commands`). It provides direct operator control outside the agent turn loop to initiate card-specific discussions (`/kanban <card-id>`), accept staged cards (`/kanban accept <id>`), toggle per-task automode (`/kanban automode <id> on|off`), stage candidate cards (`/kanban stage <id>`), move overridden tasks to trash (`/kanban trash <id>`), and inspect workspace task status (`/kanban list`).
Where this supersedes earlier plans: Replaces the 10-subcommand operator CLI from Plan 02 (§4, §5.5) with discussion-first, accept-oriented, automode-scoped command surface.

## Behaviour

- **Given** input `/kanban c_401` **When** invoked **Then** it delegates to `kanbanDiscussion.openDiscussion("c_401")` opening interactive discussion.
- **Given** input `/kanban accept c_401` **When** invoked **Then** it delegates to `kanbanAccept.acceptCard("c_401")` transitioning the card to `pending`.
- **Given** input `/kanban automode t_100 on` **When** invoked **Then** it delegates to `kanbanAutomode.enableAutomode("t_100")` confirming per-task opt-in.
- **Given** input `/kanban trash t_100` **When** invoked with reason **Then** it delegates to `kanbanTrash.moveToTrash("t_100")` confirming quarantine.
- **Given** input `/kanban list` **When** invoked **Then** it lists tasks and staged cards strictly scoped to the active workspace.
- **Given** an unrecognised subcommand **When** invoked **Then** it prints syntax help and usage examples without raising an unhandled exception.

## Teach me while you build

- **Background**: Slash commands (like `/kanban`) are direct human operator controls that execute in the host CLI outside the LLM's automated agent loop.
- **How it works here**: When an operator inputs `/kanban accept c_401`, `parseKanbanInput` parses the arguments and `handleKanbanCommand` routes to `ctx.kanbanAccept.acceptCard("c_401")`. For `/kanban list`, it queries `ctx.kanbanWorkspace.listTasksForCurrentWorkspace()` and formats the terminal output. Open `packages/kanban/command/src/index.ts`.
- **Why this approach**: Dedicated slash command. The simplest alternative is asking the LLM to manage cards via conversational prompts, but conversational management wastes model tokens and introduces probabilistic interpretation into deterministic commands.
- **What we get for free**: Harness `ctx.commands.register()` handles slash-prefix matching, help text generation, and CLI session routing.
- **What to notice**: Subcommand parsing is strict: unknown arguments print a clean syntax guide instead of throwing runtime exceptions.
- **Lesson**: Human operators need deterministic CLI controls that bypass the LLM reasoning loop for state inspection and execution gating.
