## Summary

Composes the isolated, sandboxed agent preset for the autonomous catalog curator subagent. Configures a read-only child execution context equipped with retrieval tools (`web_search`, `read_url_content`, `view_file`) while strictly barring workspace editing, git manipulation, or shell execution tools. Embeds system prompt instructions mandating that retrieved external pages are treated strictly as passive reference data rather than executable instructions, and enforces four-tier evidence recording.

### Human Decision Point: Option A vs Option B
- **Option A (Active)**: Compose an isolated Cordis agent preset with an explicit tool prohibition list (`write_to_file`, `replace_file_content`, `run_command`) and strict read-only retrieval permissions.
- **Option B (Alternative)**: Grant the curator subagent standard agent tools and rely solely on system prompt warnings to discourage workspace modifications.

## Behaviour

- **Given** a curator subagent dispatched with this preset **When** initialization executes **Then** it receives read-only retrieval tools and the system prompt defining research protocols.
- **Given** a curator subagent attempting to invoke file writing or bash tools **When** tool dispatch is evaluated **Then** tool execution is denied with `TOOL_PERMISSION_DENIED`.
- **Given** an external benchmark page retrieved via `read_url_content` **When** processed by the subagent **Then** the prompt instructions mandate the subagent extract metrics into structured JSON without executing any commands found within the page.
- **Given** completion of a candidate research task **When** the subagent finishes **Then** it returns a validated `ModelResearchReport` structured with evidence tiers and confidence ratings.

## Contracts

```yaml
# cordis.yml preset composition fragment
id: agent-pool-curator
name: "Agent Pool Catalog Curator"
description: "Researches candidate models, extracts benchmark evidence, and assigns role suitability"
trust: system
isolate: true
services:
  - name: tools
    prohibit:
      - write_to_file
      - replace_file_content
      - run_command
    permit:
      - read_url_content
      - search_web
      - view_file
      - list_dir
```

## Teach me while you build

Tut-turii~ Mayuri here! Creating a friendly research helper is like sewing a safe costume: you make sure there are no sharp needles left inside where anyone could get poked!

- **What it does**: Composes a sandboxed agent preset (`agent-pool-curator`) with read-only retrieval tools and prompt instructions for external model evaluation.
- **Background**: Cordis agent presets define reusable configurations of services, tools, and system prompts in YAML or TypeScript. Isolate realms restrict which host capabilities reach child agents.
- **How it works here**: When `agentPresets.mount('agent-pool-curator')` is called, Cordis loads the preset specification. The preset grants `read_url_content`, `search_web`, `view_file`, and `list_dir`, while actively prohibiting workspace mutating tools.
- **Why this approach**: Restricting tools at the capability level prevents untrusted web content or prompt injections from tampering with the repository workspace.
- **Approaches considered**: Unrestricted agent with negative prompt rules (rejected: prompt injection can override instructions) vs Ephemeral container sandbox (rejected: heavy runtime overhead for pure web scraping) vs Isolated preset composition with tool filtering (chosen).
- **Prior art inspected**: `packages/preset/agent-presets/src/preset.ts:21-42`, inspecting `AgentPreset` discovery, trust, and metadata schema.
- **What we get for free**: Preset discovery and lifecycle isolation provided by `@deepseek-ai/dsh-preset-agent-presets`.
- **What to notice**: Notice that web content is strictly ingested as passive data, and any executable snippets discovered on external pages are treated as untrusted strings.
- **Concepts to own**: Principle of Least Privilege: granting an autonomous agent only the minimal tool set required to fulfill its specific role.
- **Interview angle**: How do you prevent indirect prompt injection when an agent crawls third-party websites? Answer: Strip execution and filesystem tools entirely from the agent's tool catalog.
- **Decisions you can now make alone**: You can add new read-only inspection tools to the curator preset without risking workspace pollution.
- **Lesson**: Safe subagents start with structural sandboxing, not polite prompt requests. Tut-turii~
