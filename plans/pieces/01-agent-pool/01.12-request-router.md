# 01.12 — Agent Request Route Interceptor

**Set:** 01-agent-pool · **Queue:** 12 · **Depends on:** 01.06, 01.07, 01.09
**Status:** todo
**Harness primitive:** event/hook plugin · **Package:** `@deepseek-ai/dsh-agent-pool-router`

## Summary

Hooks the `agent/request` waterfall on the agent loop to dynamically resolve and bind the active model call configuration (`LlmCallConfig`) for every conversation step. Inspects the agent's assigned role, active manual pins, and real-time route availability to select the primary eligible model preset, resolving credential references per call through `ctx.credentials`. Ensures that calls are directed exclusively to currently usable routes adhering to role boundaries.

## Behaviour

- **Given** an agent dispatching a step for role `Test Writer` **When** the `agent/request` waterfall executes **Then** the router resolves the highest-priority eligible preset for `Test Writer` and injects its provider, model, and token settings into `LlmCallConfig`.
- **Given** an active manual pin for the executing role **When** `agent/request` runs **Then** the router binds the pinned model configuration directly, bypassing standard automated fallback evaluation.
- **Given** an agent step where the primary route recently became exhausted **When** `agent/request` runs **Then** the router selects the next available eligible model in the role's ordered chain.
- **Given** a preset requiring credentials **When** routing the call **Then** the router resolves the branded `CredentialRef` via `ctx.credentials.resolve()`, passing the live key to the adapter call without persisting it.
- **Given** an agent configured with no recognizable role **When** routing executes **Then** the router delegates to `next()` preserving default model selection behavior.

## Harness fit

This is an `event/hook plugin` registering a scoped listener on the `agent/request` waterfall (`packages/core/agent/src/runtime-types.ts:347`). It replaces static `LlmCallConfig` generation with role-pool-aware resolution before model execution occurs.

```typescript
export interface RouteBindingContext {
  agent: Agent
  turn: number
  step: number
  role: AgentPoolRole
  presetId: string
  provider: string
  model: string
}

export interface AgentPoolRouterPlugin {
  resolveCallConfig(agent: Agent, turn: number, step: number, defaultNext: () => Promise<LlmCallConfig>): Promise<LlmCallConfig>
}
```
