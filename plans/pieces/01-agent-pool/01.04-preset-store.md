## Summary

Manages durable storage for researched agent presets, pool rosters, and historical catalog snapshots under `ctx.storageDomain` using the `agent-pool` domain spec. Persists the complete agent-preset record: identity, route, assigned roles, strengths, limits, permitted tools, context capacity, evidence records, confidence, access category, availability status, quota scope, timestamps, and credential references (strictly forbidding raw secret storage). Preserves the last-known-good catalog and user exclusions across refreshes.

### Human Decision Point: Option A vs Option B
- **Option A (Active)**: Dedicated typed storage domain (`ctx.storageDomain`) with atomic snapshot archiving and branded credential references.
- **Option B (Alternative)**: Ad-hoc local JSON or flat files that risk file corruption, lack crash-safe ACID transactions, and risk storing plaintext secrets.

## Behaviour

- **Given** a validated preset record containing a credential reference **When** `savePreset(record)` is called **Then** the record is persisted into the `presets` domain table with its credential reference intact and zero plain secrets stored.
- **Given** an attempt to save a preset containing a raw API key instead of a branded `CredentialRef` **When** validation executes **Then** persistence is rejected with `RAW_SECRET_FORBIDDEN`.
- **Given** an active catalog and a newly generated catalog from a refresh **When** `commitCatalog(newCatalog)` is called **Then** the previous catalog is atomically archived into the `catalogSnapshots` table as last-known-good.
- **Given** an operator exclusion or custom pin applied to a model **When** a new catalog is ingested **Then** existing manual exclusions and custom pins are preserved and merged onto updated presets.

## Harness fit

This is a `Service Provider` mounted on the host plane (`ctx.agentPoolStore`) extending `@deepseek-ai/cordis.Service`. It persists structured state through `ctx.storageDomain` (`packages/storage/storage-domain/src/spec.ts:1-110`) with a strongly typed `defineDomain` spec, avoiding ad-hoc JSON files.

## Contracts

```typescript
import type { CredentialRef } from '@deepseek-ai/dsh-credentials'
import type { AccessCategory } from '@deepseek-ai/dsh-agent-pool-access'
import type { EvidenceRecord } from '@deepseek-ai/dsh-agent-pool-curator'

export interface AgentPresetRecord {
  id: string
  providerId: string
  modelId: string
  roles: readonly ('Brain' | 'Test Writer' | 'Implementer' | 'Reviewer' | 'Research/Utility')[]
  strengths: readonly string[]
  limits: readonly string[]
  tools: readonly string[]
  contextWindow: number
  maxTokens: number
  evidence: readonly EvidenceRecord[]
  confidence: number
  accessCategory: AccessCategory
  availability: 'available' | 'exhausted' | 'probing' | 'degraded' | 'disabled'
  quotaScope: 'account' | 'model' | 'shared-bucket'
  sharedBucketKey?: string
  credentialRef: CredentialRef
  isExcluded?: boolean
  exclusionReason?: string
  updatedAt: number
}

export interface AgentPoolStoreService {
  savePreset(preset: AgentPresetRecord): Promise<void>
  getPreset(id: string): Promise<AgentPresetRecord | undefined>
  listPresetsByRole(role: string): Promise<readonly AgentPresetRecord[]>
  getLastGoodCatalog(): Promise<readonly AgentPresetRecord[]>
  commitCatalog(presets: readonly AgentPresetRecord[]): Promise<void>
}
```

## Teach me while you build

Yo! Real hackers don't leave operational state floating in volatile heap memory. You lock it down into durable tables!

- **What it does**: Persists agent preset records, role rosters, and historical snapshots into a typed SQLite-backed storage domain without leaking secrets.
- **Background**: If an agent harness crashes or reboots, in-memory model rosters vanish. Flat JSON files corrupt easily during concurrent writes.
- **How it works here**: The store uses `defineDomain` from `packages/storage/storage-domain/src/spec.ts:1-110` to register tables for presets and catalog snapshots, enforcing `CredentialRef` brands on all keys.
- **Why this approach**: SQLite WAL-mode transactions give atomic commits and rollbacks without inventing ad-hoc locking mechanisms.
- **Approaches considered**: Raw JSON files in `.cache/` (rejected: no transactional safety and prone to partial writes) vs Unstructured Key-Value store (rejected: cannot efficiently query presets by role) vs Typed Cordis storageDomain (chosen: structured relational tables).
- **Prior art inspected**: SQLite Write-Ahead Logging (WAL) mode specifications and Cordis storage domain conventions.
- **What we get for free**: `ctx.storageDomain` manages table migrations, prepared statements, and disk serialization out of the box.
- **What to notice**: Raw API secret tokens are strictly blocked; only branded `CredentialRef` IDs can pass validation, preventing secret leaks to disk.
- **Concepts to own**: Domain Isolation: keeping subsystem tables inside dedicated namespaces to isolate failures and migrations.
- **Interview angle**: Why shouldn't an agent framework store API credentials directly alongside model metadata in local persistence? Answer: To maintain separation of concerns and prevent secret leaks during state serialization or debugging.
- **Decisions you can now make alone**: You can add auxiliary query indexes to the presets table without changing the public service contracts.
- **Lesson**: Never dump sensitive state into unversioned flat files; use structured storage domains with strict schema enforcement.
