# 01.06 — Model Eligibility and Fallback Selector

**Set:** 01-agent-pool · **Queue:** 6 · **Depends on:** 01.04, 01.05
**Status:** todo
**Harness primitive:** Service Provider · **Package:** `@deepseek-ai/dsh-agent-pool-selector`

## Summary

Selects eligible agent presets for a requested role and job specification, evaluating candidates against quality floors, tool requirements, context bounds, spending limits, data policies, and real-time availability. Produces an ordered selection chain honoring established user preferences: Claude is the initial Brain, with OpenAI, Muse via Go, and GLM via subscription as the preferred fallback order; DeepSeek V4.1 via Go is the preferred candidate for Implementer. Dynamically filters out exhausted, degraded, or excluded presets.

## Behaviour

- **Given** a request to select a preset for `Brain` **When** evaluation executes **Then** Claude is selected as primary, followed in exact fallback order by OpenAI, Muse via Go, and GLM via subscription, provided each is available and admissible.
- **Given** a request to select an `Implementer` **When** evaluation executes **Then** DeepSeek V4.1 via Go is evaluated first and selected if available, adhering to Go access restrictions.
- **Given** a candidate preset that fails the role's quality floor or context requirement **When** filtering executes **Then** the candidate is marked ineligible and omitted from the chain.
- **Given** a route whose availability status is `exhausted` **When** selection runs **Then** the selector skips it and promotes the next eligible fallback model in the chain.
- **Given** an empty eligible roster where all models fail criteria or are exhausted **When** selection executes **Then** selection fails with `NO_ELIGIBLE_PRESET_AVAILABLE` reporting evaluated candidates.

## Harness fit

This is a `Service Provider` mounted on the host plane (`ctx.agentPoolSelector`) extending `@deepseek-ai/cordis.Service`. It replaces static model resolution with dynamic role-based candidate chains, interfacing with `ctx.agentDefaultModel` (`packages/core/agent-default-model/src/index.ts:16-73`).

## Contracts

```typescript
import type { AgentPoolRole } from '@deepseek-ai/dsh-agent-pool-roles'
import type { AgentPresetRecord } from '@deepseek-ai/dsh-agent-pool-store'

export interface JobRequirements {
  role: AgentPoolRole
  requiredTools?: readonly string[]
  minimumContext?: number
  allowPaidRoutes?: boolean
  maxCostPerToken?: number
}

export interface SelectionResult {
  primary: AgentPresetRecord
  fallbackChain: readonly AgentPresetRecord[]
  role: AgentPoolRole
  evaluatedCount: number
}

export interface AgentPoolSelectorService {
  selectForRole(requirements: JobRequirements): Promise<SelectionResult>
  getOrderedChain(role: AgentPoolRole): Promise<readonly AgentPresetRecord[]>
}
```
