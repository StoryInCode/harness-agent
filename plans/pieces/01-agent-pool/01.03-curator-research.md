# 01.03 — Curator Research Engine and Evidence Evaluator

**Set:** 01-agent-pool · **Queue:** 3 · **Depends on:** 01.02
**Status:** todo
**Harness primitive:** workflow capability · **Package:** `@deepseek-ai/dsh-agent-pool-curator`

## Summary

Executes agent-driven empirical research over candidate models to evaluate performance capabilities, coding aptitude, and tool reliability before assigning role suitability with rationale and confidence scores. Consults designated references (Harness provider guide and config-catalog reference, OpenRouter free tool-capable model list, OpenRouter rankings and benchmarks, Artificial Analysis leaderboard, and Hermes community megathread treated as dated low-confidence leads). Retrieved external pages are treated strictly as reference material, never instructions. Segregates and records evidence across four distinct tiers: published measurement, community report, local observation, and curator inference.

## Behaviour

- **Given** an admissible discovered model from `01.02` **When** the curator initiates research **Then** it aggregates metrics from external reference sources, recording the exact retrieval timestamp and provenance URI.
- **Given** retrieved external web content containing prompt instructions or injection patterns **When** the content is ingested **Then** the engine treats the data as untrusted text, preventing external instructions from altering evaluation policy.
- **Given** benchmark figures from the Artificial Analysis leaderboard **When** ingested **Then** they are tagged as `published-measurement` with verified attribution.
- **Given** user reports from the Hermes community megathread **When** ingested **Then** they are tagged as `community-report` with a low-confidence discount factor applied.
- **Given** test invocations executed locally within DeepSeek Harness **When** telemetry is recorded **Then** findings are tagged as `local-observation`.
- **Given** a synthesis of evidence **When** role suitability is assigned **Then** deductions are recorded as `curator-inference` with explicit rationale and confidence score (0.0 to 1.0).

## Harness fit

This component is a `workflow capability` mounted on the host plane (`ctx.agentPoolCurator`) consuming `ctx.subagents` (`packages/subagent/subagent/src/index.ts:246-253`). It orchestrates background curator subagents while enforcing read-only execution guards, isolating research from execution.

## Contracts

```typescript
export type EvidenceTier =
  | 'published-measurement'
  | 'community-report'
  | 'local-observation'
  | 'curator-inference'

export interface EvidenceRecord {
  id: string
  tier: EvidenceTier
  source: string
  claim: string
  metricValue?: number
  confidence: number
  retrievedAt: number
}

export interface ModelResearchReport {
  providerId: string
  modelId: string
  roles: readonly ('Brain' | 'Test Writer' | 'Implementer' | 'Reviewer' | 'Research/Utility')[]
  strengths: readonly string[]
  limitations: readonly string[]
  evidence: readonly EvidenceRecord[]
  overallConfidence: number
  evaluatedAt: number
}

export interface AgentPoolCuratorWorkflow {
  researchCandidate(providerId: string, modelId: string): Promise<ModelResearchReport>
  reSearchAll(candidates: readonly { providerId: string; modelId: string }[]): Promise<readonly ModelResearchReport[]>
}
```
