## Summary

Coordinates active health probes to restore exhausted routes using exact provider reset times when known, or an hourly background heartbeat probe when no reset time is provided. Employs single-flight, deduplicated test probes using minimal payload requests to prevent retry storms across concurrent agents. Upon verified probe success, transitions the route from `probing` back to `available` and notifies pool selectors.

### Human Decision Point: Option A vs Option B
- **Option A (Active)**: Execute single-flight, deduplicated minimal-payload probes at exact reset timestamps or hourly intervals, preventing thundering herds.
- **Option B (Alternative)**: Let individual agents probe independently upon demand, risking retry storms and compounding rate limits across concurrent tasks.

## Behaviour

- **Given** an exhausted route with an exact reset timestamp or an elapsed 1-hour interval **When** probe conditions trigger **Then** the coordinator issues a single-flight, minimal-payload probe request.
- **Given** multiple concurrent agents requesting an exhausted route **When** a probe is in flight **Then** concurrent probe triggers collapse into the single active execution without duplicating requests.
- **Given** a probe execution outcome **When** the probe succeeds **Then** the route transitions from `probing` to `available`, or remains `exhausted` with backoff when the probe fails.

## Harness fit

This is a `Service Provider` mounted on the host plane (`ctx.agentPoolHeartbeat`) extending `@deepseek-ai/cordis.Service`. It issues lightweight test requests directly through `ctx.llm.stream()` with minimal token allocations (`packages/llm/llm/src/index.ts:276-282`).

## Teach me while you build

Listen up! When routes get knocked out by quota limits, we don't spam 50 retry pings like script kiddies and trigger a retry storm. Daru builds a lean, single-flight probe coordinator.

- **What it does**: Issues single-flight, lightweight heartbeat probes to detect when exhausted model routes recover, deduplicating concurrent probe requests.
- **Background**: When an endpoint runs out of quota, querying it repeatedly causes retry storms and worsens rate limits. A single-flight coordinator collapses multiple agent probe requests into one minimal test ping.
- **How it works here**: `AgentPoolHeartbeatService` maintains a map of scheduled probes. If `resetAt` is provided, it sleeps until that timestamp; otherwise, it defaults to a 1-hour interval. When probing, it dispatches a minimal 1-token prompt via `stream()`. If it returns successfully, it marks the route `available`.
- **Why this approach**: Centralized single-flight coordination prevents thundering herds across parallel worker agents and avoids consuming token quota on diagnostic pings.
- **Approaches considered**: Uncoordinated probe per agent (rejected: creates retry storms that extend provider rate-limit penalties) vs Passive recovery on next user request (rejected: leaves routes marked unavailable long after quota has reset) vs Single-flight coordinated probe scheduler (chosen).
- **Prior art inspected**: Go `golang.org/x/sync/singleflight` package and gRPC channel keepalive / health-checking protocols.
- **What we get for free**: Low-level stream streaming interface in `packages/llm/llm/src/index.ts:276-282` and exponential backoff jitter formulas from `packages/llm/llm-retry/src/index.ts:59-64`.
- **What to notice**: Notice that `inFlight` deduplication ensures that even if ten subagents wake up simultaneously needing the same route, only one network request hits the wire.
- **Concepts to own**: Single-flight request coalescing: suppressing redundant concurrent requests for identical resources by sharing the execution promise.
- **Interview angle**: How do you coordinate health probes across concurrent clients without overwhelming rate-limited backends? Answer: Use a single-flight mutex pattern with exact reset timestamps and exponential backoff jitter to coalesce requests.
- **Decisions you can now make alone**: You can tune the default probe payload down to a single whitespace character to minimize token consumption during heartbeat checks.
- **Lesson**: Never let multiple concurrent agents hammer a recovering endpoint. Coalesce requests at the plumbing layer.
