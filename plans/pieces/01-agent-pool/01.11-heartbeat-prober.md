# 01.11 — Hourly Heartbeat and Reset Probe Coordinator

**Set:** 01-agent-pool · **Queue:** 11 · **Depends on:** 01.09, 01.10
**Status:** todo
**Harness primitive:** Service Provider · **Package:** `@deepseek-ai/dsh-agent-pool-heartbeat`

## Summary

Coordinates active health probes to restore exhausted routes using exact provider reset times when known, or an hourly background heartbeat probe when no reset time is provided. Employs single-flight, deduplicated test probes using minimal payload requests to prevent retry storms across concurrent agents. Upon verified probe success, transitions the route from `probing` back to `available` and notifies pool selectors.

## Behaviour

- **Given** an exhausted route with a known reset timestamp **When** the reset time arrives **Then** the coordinator schedules a single-flight probe for that route.
- **Given** an exhausted route lacking a reset timestamp **When** one hour elapses since the last check **Then** the hourly heartbeat timer initiates a recovery probe.
- **Given** multiple concurrent agents needing an exhausted route **When** probe conditions are met **Then** only a single coordinated probe executes across the host, deduplicating requests and preventing retry storms.
- **Given** a successful probe response from the model endpoint **When** verification settles **Then** the route transitions from `probing` to `available` in `@deepseek-ai/dsh-agent-pool-quota`.
- **Given** a failed probe response indicating continuing quota exhaustion **When** verification fails **Then** the route remains `exhausted` and the next probe interval is scheduled with backoff.

## Harness fit

This is a `Service Provider` mounted on the host plane (`ctx.agentPoolHeartbeat`) extending `@deepseek-ai/cordis.Service`. It issues lightweight test requests directly through `ctx.llm.stream()` with minimal token allocations (`packages/llm/llm/src/index.ts:276-282`).

export interface ProbeSchedule {
  routeKey: string
  scheduledAt: number
  hasExactResetTime: boolean
  attemptCount: number
  inFlight: boolean
}

export interface ProbeOutcome {
  routeKey: string
  success: boolean
  latencyMs: number
  error?: string
  probedAt: number
}

export interface AgentPoolHeartbeatService {
  scheduleProbe(routeKey: string, resetAt?: number): void
  cancelProbe(routeKey: string): void
  executeProbe(routeKey: string): Promise<ProbeOutcome>
  listPendingProbes(): readonly ProbeSchedule[]
}
