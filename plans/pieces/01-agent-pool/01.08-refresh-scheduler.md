# 01.08 — Catalog Refresh Scheduler and Topology Reconciler

**Set:** 01-agent-pool · **Queue:** 8 · **Depends on:** 01.02, 01.03, 01.04
**Status:** todo
**Harness primitive:** event/hook plugin · **Package:** `@deepseek-ai/dsh-agent-pool-refresh`

## Summary

Coordinates weekly periodic catalog refresh cycles, processes on-demand manual refresh triggers, and dynamically reconciles catalog state in response to live provider topology notifications (`llm/adapters-updated`). Executes atomic catalog updates that preserve the last-known-good catalog snapshot, manual exclusions, and pins, while strictly preventing newly discovered but unscored models from being auto-adopted into critical roles.

## Behaviour

- **Given** a scheduled weekly timer tick **When** the refresh cron triggers **Then** discovery and curator evaluation run in the background without blocking ongoing agent tasks.
- **Given** an on-demand refresh requested via command or UI **When** `triggerRefresh('manual')` is called **Then** an immediate refresh cycle executes and publishes updated availability status.
- **Given** an adapter topology update via `llm/adapters-updated` **When** the event fires **Then** the reconciler checks for added or removed routes, marking disappeared routes unavailable without dropping historical metadata.
- **Given** a refresh cycle yielding newly discovered models **When** models are added to the catalog **Then** unscored models are tagged as unassigned and barred from critical roles until curator scoring completes.
- **Given** a refresh cycle that encounters network or provider failure **When** the update aborts **Then** the previous last-known-good catalog is retained with zero disruption to live sessions.

## Harness fit

This component is an `event/hook plugin` mounted on the host plane subscribing to `llm/adapters-updated` (`packages/llm/llm/src/types.ts:12-25`) and managing recurring timer intervals using `ctx.setInterval()`.

## Contracts

```typescript
export type RefreshTriggerSource = 'weekly-schedule' | 'manual' | 'topology-change'

export interface RefreshResult {
  source: RefreshTriggerSource
  discoveredCount: number
  updatedCount: number
  preservedPinsCount: number
  durationMs: number
  completedAt: number
}

export interface AgentPoolRefreshPlugin {
  triggerRefresh(source: RefreshTriggerSource): Promise<RefreshResult>
  isRefreshInProgress(): boolean
  getLastRefreshTime(): number | undefined
}
```
