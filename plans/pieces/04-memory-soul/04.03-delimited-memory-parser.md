## Summary

Nya~ (=^･ω･^=)🐾 Inspector Cat is sniffing out every memory note! Implements the delimiter-separated plaintext parser and serializer for `USER.md` and `MEMORY.md` files using `ENTRY_DELIMITER = '\n§\n'`. It splits raw file contents into structured note entries, trims trailing blanks, normalizes internal newlines, and provides strict external drift detection. When external edits corrupt or omit delimiters in non-empty files, it automatically creates a timestamped forensic backup (`<file>.bak.<timestamp>`) and fails closed to prevent data erasure.

### Human Decision Point: Option A vs Option B
- **Option A (Active)**: Parse notes using pure string splitting on the `\n§\n` delimiter and fail closed with timestamped backup on delimiter absence.
- **Option B (Alternative)**: Parse notes using arbitrary newline splitting or fuzzy regex heuristics, risking silent corruption when users format notes with bullet lists.

## Behaviour

- **Given** raw file text separated by `\n§\n` **When** `parseDelimitedNotes` is called **Then** it returns an array of trimmed, non-empty note strings.
- **Given** an array of note strings **When** `serializeNotes` is called **Then** it joins them with `\n§\n` and terminates with a trailing delimiter.
- **Given** an empty or whitespace-only file **When** parsed **Then** it returns an empty array with zero errors.
- **Given** a non-empty file lacking the `§` delimiter **When** `parseWithDriftGuard` executes **Then** it writes a timestamped backup and throws `MemoryDriftError`.

import { ENTRY_DELIMITER } from '@deepseek-ai/dsh-memory'

export class MemoryDriftError extends Error {
  constructor(readonly path: string, readonly backupPath: string) {
    super(`Memory file at ${path} has drifted (missing delimiter). Backup saved to ${backupPath}`)
    this.name = 'MemoryDriftError'
  }
}

export class MemoryReadError extends Error {
  constructor(readonly path: string, readonly cause: unknown) {
    super(`Failed to read memory file at ${path}: ${String(cause)}`)
    this.name = 'MemoryReadError'
  }
}

export function parseDelimitedNotes(rawContent: string): readonly string[]
export function serializeNotes(notes: readonly string[]): string
export function parseWithDriftGuard(
  filePath: string,
  rawContent: string,
  backupFn: (sourcePath: string, content: string) => Promise<string>,
): Promise<readonly string[]>

## Teach me while you build

Purr~ Let's learn how to parse structured notes without getting our claws tangled! (=^･ω･^=)

- **What it does**: Splits raw memory files into individual note entries using the `§` delimiter and creates a backup if the delimiter was removed.
- **Background**: Plaintext files are easy for humans to read, but without a dedicated delimiter, multi-line notes get mixed together. The section sign `§` acts as an unambiguous separator.
- **How it works here**: `parseDelimitedNotes` splits on `\n§\n`, trims whitespace around each entry, and filters out empty lines. `parseWithDriftGuard` verifies that non-empty files contain the delimiter; if not, it invokes `backupFn` and throws `MemoryDriftError`.
- **Why this approach**: Option A uses a distinctive Unicode delimiter (`§`) with zero external parsing dependencies, making parsing instantaneous and human-readable.
- **Approaches considered**: JSON or YAML files (rejected: noisy syntax and harder for users to edit by hand) vs Markdown header separation (rejected: notes cannot contain subheadings) vs Section sign delimiter `\n§\n` (chosen).
- **Prior art inspected**: no prior art inspected
- **What we get for free**: Native JavaScript string manipulation (`split`, `trim`, `filter`) without external regex or AST libraries.
- **What to notice**: If someone manually edits `MEMORY.md` and deletes all section marks, the drift guard immediately preserves their changes in `.bak` before throwing!
- **Concepts to own**: Fail-closed parsing, forensic data preservation, round-trip serialization invariants.
- **Interview angle**: How do you safely evolve a human-editable plaintext file format used by an automated agent? Answer: Use distinct non-colliding delimiters, validate structure on load, and preserve corrupted files in timestamped backups before failing closed.
- **Decisions you can now make alone**: You can add customized normalization (like trimming trailing newlines) without breaking the delimiter contract.
- **Lesson**: Never overwrite data you cannot parse cleanly; back it up first, then fail loud! Nya~
