## Summary

Reuses the existing `@deepseek-ai/dsh-tool-session-query` package to provide historical session transcript search for the Brain orchestrator without creating a redundant package (`REVIEW-seams.md` Finding 2). It configures the five shipped read-only tools (`session_search`, `session_event_search`, `session_trace`, `session_event_trace`, `session_event_read`) backed by host `ctx.sessionQuery`, enforcing caller workspace `cwd` authorization, cooperative query deadlines (`searchTimeoutMs: 15000`), and result bounding (`maxSearchResults: 20`) to conserve LLM context tokens.

## Behaviour

- **Given** an agent session mounting `tool-session-query` **When** `session_search` is called with a BM25 query **Then** it returns matching session hits bounded by `maxSearchResults: 20`.
- **Given** a search query **When** execution exceeds `searchTimeoutMs: 15000` **Then** it aborts cooperatively with a timeout diagnostic.
- **Given** a session query for an authorized session **When** `session_trace` is invoked **Then** it returns the session's ancestor and descendant tree.
- **Given** a search hit **When** the model calls `session_event_read` **Then** it retrieves the unabridged JSON event payload.
- **Given** a caller in workspace A querying a session created in workspace B **When** executed **Then** access is denied due to workspace `cwd` mismatch.

## Harness fit

This component is an existing model-facing `Consumer` plugin (`packages/session-query/tool-session-query/src/index.ts:1-137`) mounted in `hermes-brain` that delegates to host `ctx.sessionQuery` without duplicating packages or causing tool registration collisions.
