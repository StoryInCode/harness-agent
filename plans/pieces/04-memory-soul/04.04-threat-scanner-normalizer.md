## Summary

Implements security scanning, normalization, and sanitization for memory note writes and prompt loading. It normalizes inputs using Unicode Normalization Form KC (NFKC), blocks invisible characters (zero-width spaces `\u200B`, joiners, direction isolates), and runs regex threat pattern scanning against prompt injection vectors. On write, threats abort immediately with `MemoryThreatDetectedError`; on load, compromised entries on disk are masked with `[BLOCKED: security threat detected]` placeholders while preserving raw disk content for forensics.

## Behaviour

- **Given** note text containing Unicode homoglyphs **When** scanned **Then** it normalizes characters using NFKC before threat evaluation.
- **Given** note text containing zero-width spaces (`\u200B`) or direction overrides (`\u202A`–`\u202E`) **When** scanned on write **Then** it throws `MemoryThreatDetectedError`.
- **Given** note text containing known prompt injection patterns (system prompt overrides, role spoofing) **When** scanned on write **Then** it rejects the write with `MemoryThreatDetectedError`.
- **Given** an existing poisoned note on disk **When** loaded for prompt assembly **Then** `sanitizeNote` masks the content with `[BLOCKED: security threat detected]`.
- **Given** clean technical prose containing markdown and code blocks **When** scanned **Then** it passes validation without false positives.

## Harness fit

This component is a `workflow capability` providing stateless threat scanning and normalization algorithms used by storage providers and prompt assembly pipelines.
