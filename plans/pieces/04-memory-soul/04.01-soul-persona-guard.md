# 04.01 — SOUL Persona Prompt Contribution and Human Write Sovereignty Guard

**Set:** 04-memory-soul · **Queue:** 1 · **Depends on:** none
**Status:** todo
**Harness primitive:** agent-preset composition · **Package:** `@deepseek-ai/dsh-soul`

## Summary

Injects the founder's immutable `SOUL.md` persona into Identity Slot #1 (`deployment:persona-prefix` at order 0) across all agent sessions and enforces strict human-only write sovereignty (`INV-09`). It loads the identity text from `~/.hermes/SOUL.md` (or `HERMES_SOUL_PATH`), shadows the deployment persona prefix via `@deepseek-ai/dsh-persona`, and installs a synchronous tool execution guard via `ctx.tools.guard()` that rejects any attempt by autonomous file or shell tools to edit or delete `SOUL.md`.

## Behaviour

- **Given** an agent session mounting `hermes-brain` or `hermes-worker` **When** prompt assembly runs **Then** `SOUL.md` is rendered in Identity Slot #1 at order `DEPLOYMENT_PERSONA_PREFIX` (0).
- **Given** an autonomous tool invocation (`write_file`, `edit_file`, `str_replace_editor`) targeting `~/.hermes/SOUL.md` **When** executed **Then** `ctx.tools.guard` intercepts the call and aborts execution with `UnauthorizedSoulMutationError`.
- **Given** a shell tool invocation (`tool-bash` or `exec`) with commands modifying or deleting `SOUL.md` **When** evaluated by the tool guard **Then** execution is rejected before process spawn.
- **Given** the `memory` tool schema **When** inspected **Then** `soul` is absent from target options (`target: 'memory' | 'user'`).
- **Given** an environment where `HERMES_SOUL_PATH` is defined **When** persona loads **Then** it reads identity content from the overridden path.

## Harness fit

This component is an `agent-preset composition` combining `@deepseek-ai/dsh-persona` (`packages/preset/persona/src/index.ts:1-76`) with host tool interception via `ctx.tools.guard()` (`packages/core/tools/src/index.ts:1100-1106`). Identity must be active from turn 0 rather than loaded dynamically as a procedural skill.
