# 04.11 — Background Review Fork Dispatcher and Lineage Guard

**Set:** 04-memory-soul · **Queue:** 11 · **Depends on:** 04.09, 04.10
**Status:** todo
**Harness primitive:** subagent consumer · **Package:** `@deepseek-ai/dsh-memory-curator-review`

## Summary

Triggers autonomous background memory review forks every 10 foreground turns (`nudgeInterval: 10`) via a serial listener on `agent/turn-stopping`. It spawns a sandboxed child review subagent using the standard `ctx.subagents.start('spawn', ...)` seam, equipped with prompt templates (`MEMORY_REVIEW_PROMPT`, `SKILL_REVIEW_PROMPT`) and a strict tool allowlist (`skill`, `read_file`, `fs_search`, `skill_manage`, `memory`). It enforces an anti-recursion lineage check (`isReviewAgent`) to prevent nested review cascades, and cleanly aborts in-flight review subagents when the parent session is disposed (`REVIEW-lifecycle.md` Finding 4).

## Behaviour

- **Given** a foreground agent completing turns 1 through 9 **When** `agent/turn-stopping` fires **Then** the turn counter increments without spawning a subagent.
- **Given** turn 10 completes on a foreground agent **When** `agent/turn-stopping` fires **Then** it resets the counter and launches a review subagent via `ctx.subagents.start()`.
- **Given** an active review subagent **When** `agent/turn-stopping` fires for that child **Then** `isReviewAgent` returns true and exits immediately without incrementing counters.
- **Given** a spawned review subagent **When** tool permissions are resolved **Then** execution tools (`bash`, `write_file`, `patch`) are masked and unavailable.
- **Given** an in-flight review subagent **When** the parent session is closed or disposed **Then** the child review run is aborted immediately, preventing orphaned executions.
