# 04.13 — Review Governance Gates and Deletion Approval Staging

## Summary

Enforces two critical safety invariants during autonomous background review execution: the Read-Before-Write Skill Gate and the Unattended Memory Deletion Guard. The read-before-write gate intercepts `skill_manage` mutations, failing closed with `ReadBeforeWriteError` if the target skill was not previously viewed in the review session. The unattended deletion guard intercepts `replace` and `remove` memory mutations executed in review forks, redirecting them into an approval staging store (`~/.hermes/approvals/pending/<id>.json`) rather than allowing unattended erasure of user or operational memory.

## Behaviour

- **Given** a review child agent attempting to modify a skill **When** `skill` has not been viewed for that skill in the session **Then** it throws `ReadBeforeWriteError`.
- **Given** a review child agent that has previously viewed `skills/git/SKILL.md` **When** modifying the skill **Then** the mutation is permitted.
- **Given** a review child agent calling `memory` with `action: 'remove'` or `'replace'` **When** executed **Then** direct deletion is blocked and staged to `~/.hermes/approvals/pending/<id>.json`.
- **Given** a staged memory deletion **When** recorded **Then** `memory-deletion-staged` is appended to the curator ledger.
- **Given** a normal foreground agent session **When** calling `memory` **Then** it retains direct write authority and does not trigger deletion staging.

```typescript
import { Context } from '@deepseek-ai/cordis'

export class ReadBeforeWriteError extends Error {
  constructor(readonly skillName: string) {
    super(`Skill "${skillName}" must be inspected with skill({ name }) before modification`)
    this.name = 'ReadBeforeWriteError'
  }
}

export interface StagedMemoryApproval {
  readonly id: string
  readonly action: 'remove' | 'replace'
  readonly target: 'memory' | 'user'
  readonly payload: Record<string, unknown>
  readonly requestedAt: string
}

export class ReviewGovernanceEnforcer {
  constructor(ctx: Context, approvalsDir?: string)
  recordSkillView(skillName: string, sessionId: string): void
  checkCanWriteSkill(skillName: string, sessionId: string): void
  stageMemoryDeletion(target: 'memory' | 'user', action: 'remove' | 'replace', payload: Record<string, unknown>): Promise<string>
}

export function apply(ctx: Context): void
```
