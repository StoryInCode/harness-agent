## Summary

Implements the model-facing `memory` tool registered via `ctx.tools.register()`. It exposes single actions (`add`, `replace`, `remove`) and atomic batch `operations` for managing operational memory (`target: "memory"`) and founder preferences (`target: "user"`). It validates parameter schemas, delegates mutations to host `ctx.memory`, supports deferred budget evaluation (allowing simultaneous removal and addition at capacity), and strictly enforces `INV-09` by rejecting any attempt to target `soul`.

## Behaviour

- **Given** a tool invocation with `action: 'add'` and `target: 'memory'` **When** executed **Then** it adds the note to `MEMORY.md` via `ctx.memory.mutate()`.
- **Given** a tool invocation with `target: 'soul'` **When** evaluated **Then** parameter schema validation rejects the invocation before execution (`INV-09`).
- **Given** a store at maximum character capacity **When** a batch operation simultaneously removes 200 characters and adds 100 characters **Then** the batch succeeds without intermediate overflow failure.
- **Given** an invalid action or malformed parameter payload **When** executed **Then** it returns structured parameter error diagnostics.
- **Given** tool execution **When** inspected in client UI **Then** presentCall and presentResult render formatted note summaries.

## Harness fit

This component is an agent-plane `model-facing tool` plugin registered into `ctx.tools` (`packages/core/tools/src/index.ts:1027-1052`). Per PRESET-RULE 4, registry-contributing plugins do not need an `isolate` realm.
