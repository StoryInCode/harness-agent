# 04.06 — Local Memory Storage Provider and Turn-Snapshot Prefix Cache

**Set:** 04-memory-soul · **Queue:** 6 · **Depends on:** 04.02, 04.03, 04.04, 04.05

## Summary

Implements `LocalMemoryStore` extending `MemoryStore`, persisting `USER.md` and `MEMORY.md` under `~/.hermes/memories/`. It integrates the delimiter parser, threat scanner, and POSIX file lock to execute safe atomic batch mutations. It actively enforces Invariant `INV-08` (Prompt Prefix Cache Stability) by capturing a frozen snapshot of curated memory notes (`memory:curated-notes` at order 10) at turn assembly so mid-turn tool mutations alter disk immediately but never invalidate the active turn's prefix cache tokens.

## Behaviour

- **Given** host boot **When** `LocalMemoryStore` loads **Then** it registers `memory:curated-notes` on `ctx.systemPrompt` at order 10.
- **Given** an active agent turn **When** prompt assembly runs **Then** it renders the frozen snapshot captured at turn initialization (`INV-08`).
- **Given** a tool mutation modifying `MEMORY.md` mid-turn **When** committed to disk **Then** disk updates immediately while the active turn's prompt snapshot remains byte-identical (`INV-08`).
- **Given** a batch mutation **When** `mutate()` executes **Then** operations apply sequentially under POSIX lock and validate against character limits only at final resulting state.
- **Given** a mutation resulting in character overflow **When** evaluated **Then** it throws `MemoryBudgetExceededError` and aborts file commit.

## Harness fit

This component is a host-plane `Service Provider` registering `LocalMemoryStore` under `ctx.memory` (`PRESET-RULES.md:6`) and contributing prompt section `memory:curated-notes` at order 10 (`packages/core/system-prompt/src/index.ts:121-178`).

## Contracts

```typescript
import { Context } from '@deepseek-ai/cordis'
import z from '@deepseek-ai/schemastery'
import { MemoryStore, MEMORY_CHAR_LIMIT, USER_CHAR_LIMIT } from '@deepseek-ai/dsh-memory'
import type { MemoryBatchResult, MemoryBudget, MemoryNote, MemoryOperation, MemoryTarget } from '@deepseek-ai/dsh-memory'

export interface Config {
  memoriesDir?: string
  memoryCharLimit?: number
  userCharLimit?: number
  lockTimeoutMs?: number
}

export const Config: z<Config> = z.object({
  memoriesDir: z.string().default('~/.hermes/memories'),
  memoryCharLimit: z.number().default(MEMORY_CHAR_LIMIT),
  userCharLimit: z.number().default(USER_CHAR_LIMIT),
  lockTimeoutMs: z.number().default(5000),
})

export class LocalMemoryStore extends MemoryStore {
  static inject = ['fs', 'systemPrompt']
  constructor(ctx: Context, config?: Config)
  getNotes(target: MemoryTarget): Promise<readonly MemoryNote[]>
  getRawContent(target: MemoryTarget): Promise<string>
  getBudget(target: MemoryTarget): Promise<MemoryBudget>
  mutate(target: MemoryTarget, operations: readonly MemoryOperation[]): Promise<MemoryBatchResult>
  getTurnPromptSnapshot(): string
  captureTurnPromptSnapshot(): void
}
```
