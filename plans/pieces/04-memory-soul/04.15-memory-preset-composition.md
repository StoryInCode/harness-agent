# 04.15 — Memory and Curator Host Bundle Patch and Preset Composition

**Set:** 04-memory-soul · **Queue:** 15 · **Depends on:** 04.01, 04.06, 04.07, 04.08, 04.09, 04.10, 04.11, 04.12, 04.13, 04.14

**Harness primitive:** patch layer · **Package:** `@deepseek-ai/dsh-memory-presets`

## Summary

Configures host bundle wiring and agent preset compositions for memory, soul, and curator capabilities. In the host bundle (`packages/bundle/base/cordis.patch.yml`), it registers storage domain routes (`curator: sqlite`) and mounts host singleton services (`ctx.memory`, `ctx.memoryCurator`). In agent presets (`presets/hermes-brain/agent.cordis.yml` and `hermes-worker`), it mounts `@deepseek-ai/dsh-soul` (Identity Slot #1), `@deepseek-ai/dsh-tool-memory`, and (in `hermes-brain`) existing `@deepseek-ai/dsh-tool-session-query`.

## Behaviour

- **Given** host initialization **When** the base bundle loads **Then** `LocalMemoryStore` and `CuratorRuntime` mount as host singletons on the root container.
- **Given** a `hermes-brain` session **When** initialized **Then** it mounts `tool-memory`, `tool-session-query` (bounded to 20 hits), and renders `SOUL.md` at order 0.
- **Given** a `hermes-worker` session **When** initialized **Then** it mounts `tool-memory` and renders `SOUL.md` at order 0.
- **Given** child review subagents spawned by the curator **When** initialized **Then** they mount without persona collisions and without re-registering host singletons.
- **Given** HMR reload of the memory bundle **When** executed **Then** prompt sections and tools unbind cleanly without memory leaks.

## Harness fit

This component is a `patch layer` updating host configuration (`cordis.patch.yml`) and agent presets (`agent.cordis.yml`) per PRESET-RULES 1, 4, and 6 (`PRESET-RULES.md`).

## Contracts

```yaml
# packages/bundle/base/cordis.patch.yml (Host Plane)
'@deepseek-ai/dsh-storage-domain':
  routes:
    curator: sqlite

- id: memory-store
  name: '@deepseek-ai/dsh-memory-local'
  config:
    memoriesDir: ~/.hermes/memories

- id: memory-curator
  name: '@deepseek-ai/dsh-memory-curator-lifecycle'
  config:
    staleAfterDays: 30
    archiveAfterDays: 90
    minIdleHours: 2.0
    sweepIntervalHours: 168.0
    housekeepingTickIntervalMs: 60000

# presets/hermes-brain/agent.cordis.yml (Agent Plane)
- id: soul
  name: '@deepseek-ai/dsh-soul'

- id: tool-memory
  name: '@deepseek-ai/dsh-tool-memory'

- id: tool-session-query
  name: '@deepseek-ai/dsh-tool-session-query'
  config:
    maxSearchResults: 20
    searchTimeoutMs: 15000

# presets/hermes-worker/agent.cordis.yml (Agent Plane)
- id: soul
  name: '@deepseek-ai/dsh-soul'

- id: tool-memory
  name: '@deepseek-ai/dsh-tool-memory'
```
