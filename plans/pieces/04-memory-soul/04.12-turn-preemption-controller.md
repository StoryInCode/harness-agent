# 04.12 — Human Turn Preemption Controller and Cancellation Watchdog

## Summary

Implements the low-latency human turn preemption controller for background review forks. It subscribes to incoming user turn signals (`agent/inbox/spliced` and `agent/pre-step`) on the parent agent. When a user input message arrives while a background review subagent is executing, it immediately triggers the child's `AbortController`, calls `run.dispose()`, and enforces a strict 2.0-second cancellation watchdog deadline (`preemptionTimeoutMs: 2000`). It records the preemption event in the curator ledger and releases system resources without delaying the human turn.

## Behaviour

- **Given** an active background review subagent **When** a user message arrives in the parent agent's inbox **Then** it immediately signals preemption abort.
- **Given** preemption is signaled **When** the child subagent settles within 2.0 seconds **Then** it cleanly disposes child resources and logs preemption to the ledger.
- **Given** preemption is signaled **When** the child fails to exit within 2,000ms **Then** the watchdog unmounts the child context forcibly.
- **Given** a parent agent with no active review subagent **When** a user message arrives **Then** the preemption hook is a no-op and user processing proceeds without delay.
- **Given** preemption completes **When** audited **Then** the foreground user turn begins without being blocked by background cleanup.
