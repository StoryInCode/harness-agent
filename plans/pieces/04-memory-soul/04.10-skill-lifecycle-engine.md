# 04.10 — Skill Lifecycle Decay Engine and Preservation Invariant

## Summary

Implements the deterministic skill lifecycle state machine and periodic housekeeping engine. It transitions unreferenced skills from `active` to `stale` at 30 days of inactivity, and from `stale` to `archived` at 90 days. It strictly enforces the Skill Preservation Invariant: retired skills are never deleted, but safely moved into timestamped directories (`~/.hermes/skills/.archive/<name>-<YYYYMMDDHHMMSS>/`). When any agent invokes a stale skill, it is immediately reactivated to `active`. Housekeeping runs on a periodic timer with configurable `housekeepingTickIntervalMs` (`REVIEW-lifecycle.md` Gap 3) and inactivity gating.

## Behaviour

- **Given** an active skill unreferenced for >30 days **When** housekeeping runs **Then** its state transitions to `stale` and `curator/transition` is emitted.
- **Given** a stale skill unreferenced for >90 days **When** housekeeping runs **Then** the directory moves to `.archive/<name>-<ts>/` and state transitions to `archived`.
- **Given** a skill in `stale` state **When** invoked via the `skill` tool **Then** `tools/post-execute` immediately reactivates it to `active` and records the invocation.
- **Given** an archived skill **When** inspected **Then** its files remain intact under `.archive/` (zero permanent deletion).
- **Given** a housekeeping evaluation **When** host idle time is under `minIdleHours: 2.0` **Then** the sweep is bypassed.

## Harness fit

This component is a host-plane `workflow capability` executing deterministic decay transitions against `ctx.storageDomain` and notifying registries via `skills/change`.

export interface LifecycleConfig {
  staleAfterDays: number             // default 30
  archiveAfterDays: number           // default 90
  minIdleHours: number               // default 2.0
  sweepIntervalHours: number         // default 168.0
  housekeepingTickIntervalMs: number // default 60000 (REVIEW-lifecycle Gap 3)
  skillsDir: string                  // default '~/.hermes/skills'
}

export class SkillLifecycleManager {
  constructor(ctx: Context, config?: Partial<LifecycleConfig>)
  recordInvocation(skillName: string, sessionId: string): Promise<void>
  evaluateDecay(now?: Date): Promise<readonly CuratorLedgerEntry[]>
  reactivateSkill(skillName: string): Promise<void>
  startHousekeepingTimer(): () => void
}
