# 04.14 — Repeated Lesson Candidate Axiom Promotion Engine

## Summary

Implements Invariant `M-013`: promoting recurring lessons and defects discovered across multiple independent sessions into candidate axioms. When a procedural constraint or environment failure recurs across >= 2 independent sessions, it stages a candidate proposal document to `~/.hermes/candidate-axioms/<id>.json` and emits `'curator/candidate-axiom-promoted'`. It maintains a strict dependency edge to the Colocated Axioms subsystem (`03.01`, `03.08`), enabling canonical promotion to target `AGENTS.md` files without duplicating axiom evaluation logic.

## Behaviour

- **Given** a lesson recorded in 1 session **When** evaluated **Then** it is retained in review notes without triggering candidate axiom promotion.
- **Given** the same lesson recurs in a 2nd independent session **When** evaluated **Then** it stages a proposal at `~/.hermes/candidate-axioms/<id>.json` and emits `'curator/candidate-axiom-promoted'`.
- **Given** a staged candidate proposal **When** approved for canonical promotion **Then** `ctx.axiomPromoter.promoteToColocatedAxiom()` (`03.08`) formats and appends the checkable block into the target package's `AGENTS.md`.
- **Given** a proposed candidate payload lacking required occurrence metadata **When** validation runs **Then** it rejects the proposal before writing to disk.

## Harness fit

This component is a host-plane `workflow capability` detecting recurring patterns and publishing Cordis host events, bridging self-learning into the axiom subsystem via dependency edges.

  readonly id: string                  // "cand_ax_" + 8 hex chars
  readonly statement: string
  readonly reason: string
  readonly occurrences: readonly CandidateAxiomOccurrence[]
  readonly proposedTargetAgentsMd?: string
  readonly createdAt: string
}

declare module '@deepseek-ai/cordis' {
  interface Events {
    'curator/candidate-axiom-promoted': (proposal: CandidateAxiomProposal) => void
  }
}

export class CandidateAxiomPromoter {
  constructor(ctx: Context, candidateAxiomsDir?: string)

    key: string,

    statement: string,

    proposedTarget?: string,
  ): Promise<CandidateAxiomProposal | null>

}
