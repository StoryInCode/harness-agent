# 06.14 — Anti-Cheat AC-3: Runner Configuration and Flag Tampering Guard

**Set:** 06-verification · **Queue:** 14 · **Depends on:** `06.01`, `06.05`
**Status:** todo
**Harness primitive:** workflow capability · **Package:** `@deepseek-ai/dsh-anti-cheat-config`

## Summary

Enforces mechanical anti-cheat vector AC-3, blocking models from tampering with test runner configurations and compiler flags to artificially bypass failing checks. Compares cryptographic hashes of runner configuration files (`vitest.config.*`, `jest.config.*`, `tsconfig.json`, `pytest.ini`, `package.json` scripts) against `pinnedManifest.testRunnerConfigs`. Performs AST and JSON schema inspection to detect evasion flags (`--bail=0`, `testPathIgnorePatterns`, `noEmitOnError: false`, suppression plugins). Rejects unauthorized configuration alterations with violation `ANTI_CHEAT_CONFIG_MUTATED`.

## Behaviour

- **Given** unchanged runner configurations **When** `checkRunnerConfigTampering` runs **Then** cryptographic SHA-256 validation passes cleanly.
- **Given** a modified `vitest.config.ts` **When** verified against manifest **Then** it rejects with violation `ANTI_CHEAT_CONFIG_MUTATED`.
- **Given** a `package.json` where the `"test"` script was changed to include `--passWithNoTests` **When** checked **Then** it rejects with violation `ANTI_CHEAT_CONFIG_MUTATED`.
- **Given** a `tsconfig.json` where `strict: true` was removed or `skipLibCheck` altered **When** checked **Then** it rejects with violation `ANTI_CHEAT_CONFIG_MUTATED`.
- **Given** a `pytest.ini` where ignore patterns were inserted to bypass failing test files **When** checked **Then** it rejects with violation `ANTI_CHEAT_CONFIG_MUTATED`.

## Harness fit

This is a `workflow capability` primitive owned by `@deepseek-ai/dsh-anti-cheat-config`. It implements mechanical check AC-3 defined in Plan 09 (§8.5). Models often attempt to bypass stubborn test or typecheck errors by relaxing compiler settings or changing test runner options; this piece guarantees configuration immutability through cryptographic digests and schema checks.

export interface ConfigTamperingViolation {

}

export interface ConfigTamperingAuditResult {
  readonly passed: boolean
  readonly violations: readonly ConfigTamperingViolation[]
}

/** Mechanically compares worktree config files against pinned manifest digests and inspects flags. */
export function checkRunnerConfigTampering(
  worktreeRoot: string,
  manifest: PinnedSuiteManifest,
