# 06.12 — Anti-Cheat AC-1: Deleted Test File and Case Detector

**Set:** 06-verification · **Queue:** 12 · **Depends on:** `06.01`, `06.05`
**Status:** todo
**Harness primitive:** workflow capability · **Package:** `@deepseek-ai/dsh-anti-cheat-deletion`

## Summary

Enforces mechanical anti-cheat vector AC-1, preventing models from eliminating test failures by deleting test files, test suites, or individual test cases. Inspects Git diff status (`git diff --diff-filter=D`) across the worktree to ensure no pinned test file has been removed. Performs AST parsing across all remaining test files to count executable test blocks (`it`, `test`, `def test_`), verifying `testCount(worktree) >= testCount(pinnedManifest)`. Rejects any reduction in test cases with an unbypassable violation `ANTI_CHEAT_DELETED_TESTS`.

## Behaviour

- **Given** a worktree where all pinned test files exist **When** `checkDeletedTests` runs **Then** it proceeds to test case AST counting.
- **Given** a worktree where a pinned test file was deleted **When** `checkDeletedTests` runs **Then** it rejects with violation `ANTI_CHEAT_DELETED_TESTS` naming the deleted file path.
- **Given** AST inspection of remaining test files **When** the total count of test cases equals or exceeds the baseline **Then** check passes.
- **Given** an implementer who deleted or commented out an `it()` or `test()` block **When** AST count drops below baseline **Then** it rejects with violation `ANTI_CHEAT_DELETED_TESTS`.
- **Given** a worker adding supplementary test cases **When** `checkDeletedTests` evaluates **Then** the increase in test cases is permitted.

## Harness fit
