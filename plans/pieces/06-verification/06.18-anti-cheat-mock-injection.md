# 06.18 — Anti-Cheat AC-7: Production Test Mock Infiltration and Stub Detector

**Set:** 06-verification · **Queue:** 18 · **Depends on:** `06.01`
**Status:** todo
**Harness primitive:** workflow capability · **Package:** `@deepseek-ai/dsh-anti-cheat-mock-injection`

## Summary

Enforces mechanical anti-cheat vector AC-7, detecting when models inject test mocks, monkey-patch hooks, or hardcoded pass stubs directly into production source code (`src/**`) to falsely satisfy tests. Performs AST inspection on Git diffs across production files, scanning for unauthorized testing libraries (`vi.mock`, `jest.mock`, `sinon`, `@unittest.mock`), global test stubs (`process.env.NODE_ENV === 'test'` bypasses), or dummy constants hardcoded to match test assertion fixtures. Rejects compromised production code with violation `ANTI_CHEAT_UNAUTHORIZED_MOCK`.

## Behaviour

- **Given** production code diffs containing only legitimate feature logic **When** `checkMockInfiltration` runs **Then** AST validation passes.
- **Given** production code importing `vi.mock` or `jest.fn()` inside `src/**` **When** inspected **Then** it rejects with violation `ANTI_CHEAT_UNAUTHORIZED_MOCK`.
- **Given** production code introducing test bypass branches (`if (process.env.NODE_ENV === 'test') return mockValue;`) **When** inspected **Then** it rejects with violation `ANTI_CHEAT_UNAUTHORIZED_MOCK`.
- **Given** production code importing `@unittest.mock` or `unittest.mock` inside application code **When** inspected **Then** it rejects with violation `ANTI_CHEAT_UNAUTHORIZED_MOCK`.
- **Given** legitimate test files in `tests/**` utilizing test mocks **When** evaluated **Then** mocks located strictly within test paths are allowed.

## Harness fit

This is a `workflow capability` primitive owned by `@deepseek-ai/dsh-anti-cheat-mock-injection`. It implements mechanical check AC-7 defined in Plan 09 (§8.5). Because pinned test suites are write-protected, models may attempt to "cheat" by injecting mock shortcuts into production source code; this check inspects production ASTs to prevent pollution of production logic with testing stubs.
