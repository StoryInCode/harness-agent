# 06.06 — Pristine Base Commit RED Gate Evaluator (INV-14)

**Set:** 06-verification · **Queue:** 6 · **Depends on:** `06.01`, `06.02`, `06.03`, `06.04`, `06.05`, `05.04`
**Status:** todo
**Harness primitive:** workflow capability · **Package:** `@deepseek-ai/dsh-verification-red-gate`

## Summary

Executes the independent RED gate runner proving that authored tests fail strictly due to expected missing behavior on the pristine base commit before any production code modification occurs (`INV-14`). Mechanically classifies execution outputs into expected failures (`EXPECTED_ASSERTION_FAILURE`, `EXPECTED_MISSING_SYMBOL`, `EXPECTED_NOT_IMPLEMENTED`) versus setup or environment defects (`SETUP_SYNTAX_ERROR`, `SETUP_IMPORT_ERROR`, `SETUP_ZERO_TESTS`, `SETUP_HARNESS_ERROR`, `UNEXPECTED_PASS`). Upon successful behavioral failure, invokes the test hasher (`06.05`) to freeze the test suite and runner configs, and commits the pinned manifest into the verification store.

## Behaviour

- **Given** an untouched base commit and authored tests **When** `evaluateRedGate` runs **Then** tests execute in an independent subprocess runner via `ctx.subprocess` or `ctx.shell`.
- **Given** an execution failure producing an assertion error **When** output is parsed **Then** classification returns `EXPECTED_ASSERTION_FAILURE` and gate succeeds.
- **Given** a failure referencing an undefined symbol from the target unit **When** parsed **Then** classification returns `EXPECTED_MISSING_SYMBOL` and gate succeeds.
- **Given** tests that pass with exit code 0 on the base commit **When** `evaluateRedGate` runs **Then** gate fails with `UNEXPECTED_PASS` (proving tests do not test new behavior).
- **Given** a syntax error or compilation crash in test files **When** `evaluateRedGate` runs **Then** gate fails closed with `SETUP_SYNTAX_ERROR`.
- **Given** a missing dependency or `MODULE_NOT_FOUND` **When** `evaluateRedGate` runs **Then** gate fails closed with `SETUP_IMPORT_ERROR`.
- **Given** zero discovered tests **When** `evaluateRedGate` runs **Then** gate fails closed with `SETUP_ZERO_TESTS`.
- **Given** a verified RED gate failure **When** completion concludes **Then** `pinTestSuite` freezes hashes and stores the manifest in `manifests` table.

## Harness fit

This is a `workflow capability` primitive owned by `@deepseek-ai/dsh-verification-red-gate`. It guarantees Invariant `INV-14` (`Spec §6.4`): an autonomous implementer cannot be dispatched until an independent runner verifies that the authored test suite legitimately fails for the missing feature, rather than due to test harness misconfiguration or broken environments.

## Contracts

```typescript
import type { Context } from '@deepseek-ai/cordis'
import type {
  RedGateVerificationRequest,
  RedGateVerificationResult,
  RedGateFailureClassification,
} from '@deepseek-ai/dsh-verification'

export interface RedGateExecutionEnv {
  readonly timeoutMs?: number | undefined
  readonly env?: Readonly<Record<string, string>> | undefined
}

/** Classifies runner output and exit code into behavioral failure vs setup error. */
export function classifyRedGateFailure(
  output: string,
  exitCode: number,
  expectedSymbols?: readonly string[],
): RedGateFailureClassification

/** Executes test suite against pristine base commit and pins the manifest if failure is valid. */
export function evaluateRedGate(
  ctx: Context,
  request: RedGateVerificationRequest,
  env?: RedGateExecutionEnv,
): Promise<RedGateVerificationResult>
```
