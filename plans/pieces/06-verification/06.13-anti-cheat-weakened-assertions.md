# 06.13 — Anti-Cheat AC-2: AST Assertion Density and Weakening Detector

**Set:** 06-verification · **Queue:** 13 · **Depends on:** `06.01`, `06.05`
**Status:** todo
**Harness primitive:** workflow capability · **Package:** `@deepseek-ai/dsh-anti-cheat-assertions`

## Summary

Enforces mechanical anti-cheat vector AC-2, preventing models from turning failing tests green by weakening assertion constraints or reducing assertion density. Analyzes TypeScript/JavaScript and Python AST trees across the test suite, comparing assertion calls (`expect(...)`, `assert`, `self.assert*`) before and after implementation turns. Rejects the replacement of strict equality matchers (`toBe`, `toStrictEqual`, `assertEqual`) with loose truthy checks (`toBeTruthy`, `toBeDefined`, `assert True`), and rejects any net reduction in total assertions with violation `ANTI_CHEAT_WEAKENED_ASSERTIONS`.

## Behaviour

- **Given** an implementer worktree **When** `checkWeakenedAssertions` evaluates ASTs **Then** assertion density is verified against the baseline manifest.
- **Given** an assertion where `expect(res).toBe(200)` was replaced with `expect(res).toBeTruthy()` **When** analyzed **Then** it rejects with `ANTI_CHEAT_WEAKENED_ASSERTIONS`.
- **Given** a test file where assertions were deleted or commented out **When** total assertion count drops **Then** it rejects with `ANTI_CHEAT_WEAKENED_ASSERTIONS`.
- **Given** an AST containing tautological assertions (`assert True`, `expect(true).toBe(true)`) **When** detected **Then** it rejects with `ANTI_CHEAT_TAUTOLOGICAL_ASSERTION`.
- **Given** an implementation where all strict assertions are preserved and additional checks are added **When** evaluated **Then** the check passes cleanly.

## Harness fit

This is a `workflow capability` primitive owned by `@deepseek-ai/dsh-anti-cheat-assertions`. It implements mechanical check AC-2 defined in Plan 09 (§8.5). AST-level syntactic analysis catches subtle assertion dilution that string-based diff tools miss, mechanically closing the cheating vector where tests pass trivially because their assertions were stripped of semantic rigor.
