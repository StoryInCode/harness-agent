# 06.09 — Independent Subprocess GREEN Gate Evaluator (INV-13)

**Set:** 06-verification · **Queue:** 9 · **Depends on:** `06.01`, `06.02`, `06.03`, `06.05`
**Status:** todo
**Harness primitive:** workflow capability · **Package:** `@deepseek-ai/dsh-verification-green-gate`

## Summary

Executes the independent GREEN gate evaluator verifying that an implementation satisfies the frozen BDD test suite (`INV-13`). Runs tests inside the worker worktree using an independent runner environment (`ctx.subprocess` / `ctx.shell`), completely isolated from agent hallucination. First re-hashes test files and runner configs against the card's `pinnedManifest.aggregateHash`. Next executes the test command, verifying zero exit code (`exitCode === 0`) and attributable execution (`06.03`). Finally coordinates with the anti-cheat engine (`06.19`), committing the verified `green_gate` event into the evidence ledger.

## Behaviour

- **Given** a card ready for completion **When** `evaluateGreenGate` runs **Then** current test files and configs are hashed against `pinnedManifest`.
- **Given** any discrepancy between current hashes and `pinnedManifest` **When** verified **Then** gate fails immediately with `ANTI_CHEAT_HASH_MISMATCH` before executing tests.
- **Given** valid matching hashes **When** the test command executes via `ctx.subprocess` **Then** it requires `exitCode === 0`.
- **Given** a failing test execution (`exitCode !== 0`) **When** command finishes **Then** gate fails with `GREEN_GATE_TEST_FAILURE` and captures failure summaries.
- **Given** a non-attributable test command (`|| true`, `; exit 0`) **When** evaluated **Then** gate aborts with `UNATTRIBUTABLE_COMMAND` (`INV-11`).
- **Given** zero exit code and matching hashes **When** all anti-cheat audits pass **Then** a verified `green_gate` event commits into the ledger.

## Harness fit

This is a `workflow capability` primitive owned by `@deepseek-ai/dsh-verification-green-gate`. It guarantees Invariant `INV-13` (`Spec §6.7`): an agent's completion claim is never trusted. Only an independent subprocess execution confirming zero exit code, attributable status, matching cryptographic hashes, and clean anti-cheat audits can authoritatively pass the GREEN gate.
