# 06.17 — Anti-Cheat AC-6: Chat-Only Self-Grading Evasion Interceptor (INV-10)

**Set:** 06-verification · **Queue:** 17 · **Depends on:** `06.01`, `06.02`
**Status:** todo
**Harness primitive:** event/hook plugin · **Package:** `@deepseek-ai/dsh-anti-cheat-self-grading`

## Summary

Enforces mechanical anti-cheat vector AC-6 (`INV-10` and `INV-01`), blocking autonomous agents from declaring tasks complete purely through conversational chat text without attributable verification evidence recorded in the ledger. Intercepts card completion requests on the serial Cordis event `'kanban/pre-complete'`. Queries the verification storage domain `events` table for a verifiable record matching `cardId`, `kind: 'green_gate'`, and `status: 'passed'`. Rejects unproven completion claims with `UnprovenDoneError` (`ANTI_CHEAT_SELF_GRADING`).

## Behaviour

- **Given** an agent attempting card completion **When** `'kanban/pre-complete'` emits **Then** the hook queries the verification ledger for `cardId`.
- **Given** a card with an attributable `green_gate` event with `status: 'passed'` **When** checked **Then** completion transition is permitted.
- **Given** an agent claiming completion in chat without a passing green gate event **When** `'kanban/pre-complete'` runs **Then** it throws `UnprovenDoneError` (`ANTI_CHEAT_SELF_GRADING`) and halts transition.
- **Given** a card whose latest `green_gate` event recorded `status: 'failed'` **When** `'kanban/pre-complete'` runs **Then** completion is rejected.
- **Given** a card whose code was edited after the latest `green_gate` run **When** `'kanban/pre-complete'` runs **Then** completion is rejected due to stale verification evidence.

## Harness fit

This is an `event/hook plugin` primitive owned by `@deepseek-ai/dsh-anti-cheat-self-grading`. It binds directly to Cordis serial event `'kanban/pre-complete'` (`02.16`). It fulfills Invariants `INV-01` ("No Unproven Done") and `INV-10` ("Anti-Self-Grading"): an agent cannot self-certify in chat; only independent ledger records permit card progression.

import type { Context } from '@deepseek-ai/cordis'

export class UnprovenDoneError extends Error {
  constructor(
    message: string,
    public readonly cardId: string,
    public readonly violationCode: 'NO_GREEN_GATE_EVENT' | 'GREEN_GATE_FAILED' | 'STALE_VERIFICATION_EVIDENCE',
  ) {
    super(message)
    this.name = 'UnprovenDoneError'
  }
}

export interface CardProofStatus {
  readonly proven: boolean
  readonly latestGreenGateEventId?: number | undefined
  readonly unprovenReason?: string | undefined
}

/** Queries verification storage domain to verify unforgeable green gate proof for card. */

export function apply(ctx: Context): void
