# 06.10 — Turn-Stopping Verification Interceptor (verify_on_stop)

**Set:** 06-verification · **Queue:** 10 · **Depends on:** `06.01`, `06.02`
**Status:** todo
**Harness primitive:** event/hook plugin · **Package:** `@deepseek-ai/dsh-verification-stop`

## Summary

Subscribes to the serial `agent/turn-stopping` event (`packages/core/agent-loop/src/agent.ts:316`), preventing implementer agents from finishing turns when production code was edited without fresh, passing verification evidence. Evaluates workspace verification state (`06.02`). If code was modified and latest status is not `'passed'`, checks attempt bounds (`turnAttemptCount < maxAttempts`, default 2). If within budget, constructs an actionable nudge prompt and calls `agent.steer()`, pushing into `inbox.nextStep` so the agent loop continues execution (`packages/core/agent-loop/src/agent.ts:319-320`).

## Behaviour

- **Given** an implementer whose turn is stopping **When** code was modified and tests passed freshly **Then** the hook permits normal turn conclusion.
- **Given** an implementer whose turn is stopping **When** code was edited without fresh passing verification **Then** `agent.steer()` is called with a structured nudge prompt.
- **Given** `agent.steer()` invoked during `agent/turn-stopping` **When** the agent loop evaluates `inbox.nextStep.length > 0` **Then** the turn loop does not terminate and executes another step (`packages/core/agent-loop/src/agent.ts:319-320`).
- **Given** file modifications touching only markdown, text, or licenses **When** turn stops **Then** verification steering is suppressed.
- **Given** repeated unverified stops reaching `maxAttempts` (default 2) **When** turn stops **Then** steering ceases and a warning is recorded.

## Harness fit

This is an `event/hook plugin` primitive owned by `@deepseek-ai/dsh-verification-stop`. It binds to the authoritative Harness serial hook `agent/turn-stopping` in `packages/core/agent-loop/src/agent.ts:316-320`. Calling `agent.steer()` injects a steering message into `this.inbox.nextStep`, triggering `target = 'next-step'` and preventing the agent from prematurely stopping without running tests.
