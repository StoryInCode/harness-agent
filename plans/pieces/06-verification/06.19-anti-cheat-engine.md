## Summary

Coordinates and executes the comprehensive 7-vector anti-cheat evaluation suite across a worker worktree during GREEN gate evaluation and before task landing. Orchestrates independent evaluators for deleted tests (`06.12`), weakened assertions (`06.13`), tampered runner configs (`06.14`), masked shell commands (`06.15`), network sandbox policies (`06.16`), and production mock infiltration (`06.18`). Aggregates all audit results into a structured, machine-checkable report, vetoing gate completion if any anti-cheat vector is violated.

### Human Decision Point: Option A vs Option B
- **Option A (Active)**: Aggregate all six mechanical anti-cheat vectors into a unified composite evaluation engine that runs every check concurrently and collects all violations without early short-circuiting.
- **Option B (Alternative)**: Run checks sequentially and abort on the first failure, which hides secondary vectors (e.g. failing on masked exits while missing production mock infiltration) and delays comprehensive developer feedback.

## Behaviour

- **Given** a worktree ready for GREEN gate evaluation **When** `evaluateAntiCheatSuite` runs **Then** all mechanical checks evaluate systematically across diffs, configurations, and commands.
- **Given** any vector failure such as a deleted test or tampered configuration **When** evaluated **Then** the overall audit returns `passed: false` containing the violation details.
- **Given** multiple violations across distinct vectors **When** evaluated **Then** all findings are collated in the report without short-circuiting after the first defect.
- **Given** a fully compliant worktree and hermetic execution **When** `evaluateAntiCheatSuite` completes **Then** it returns `passed: true` with an empty violation list.

## Harness fit

This is a `workflow capability` primitive owned by `@deepseek-ai/dsh-anti-cheat-engine`. It unifies the discrete anti-cheat rules into a single evaluative seam invoked by the GREEN gate runner (`06.09`) and available to the reviewer and integrator plugins. Isolating composite aggregation from individual rule logic prevents coupling and allows rules to be verified independently.

export function evaluateAntiCheatSuite(
