# 06.19 — Composite Anti-Cheat Audit Engine

**Set:** 06-verification · **Queue:** 19 · **Depends on:** `06.12`, `06.13`, `06.14`, `06.15`, `06.16`, `06.18`
**Status:** todo
**Harness primitive:** workflow capability · **Package:** `@deepseek-ai/dsh-anti-cheat-engine`

## Summary

Coordinates and executes the comprehensive 7-vector anti-cheat evaluation suite across a worker worktree during GREEN gate evaluation and before task landing. Orchestrates independent evaluators for deleted tests (`06.12`), weakened assertions (`06.13`), tampered runner configs (`06.14`), masked shell commands (`06.15`), network sandbox policies (`06.16`), and production mock infiltration (`06.18`). Aggregates all audit results into a structured, machine-checkable report, vetoing gate completion if any anti-cheat vector is violated.

## Behaviour

- **Given** a worktree ready for GREEN gate evaluation **When** `evaluateAntiCheatSuite` runs **Then** all mechanical checks evaluate systematically.
- **Given** any vector failure (e.g. deleted test or modified config) **When** evaluated **Then** overall audit returns `passed: false` containing the violation details.
- **Given** multiple violations across distinct vectors **When** evaluated **Then** all findings are collated in the report without short-circuiting after the first.
- **Given** a fully compliant worktree **When** `evaluateAntiCheatSuite` completes **Then** it returns `passed: true` with empty violation list.
- **Given** a completed audit report **When** attached to `GreenGateVerificationResult` **Then** it provides immutable proof of verification integrity.

## Harness fit

This is a `workflow capability` primitive owned by `@deepseek-ai/dsh-anti-cheat-engine`. It unifies the discrete anti-cheat rules into a single evaluative seam invoked by the GREEN gate runner (`06.09`) and available to the reviewer and integrator plugins. Isolating composite aggregation from individual rule logic prevents coupling and allows rules to be verified independently.

  readonly worktreeRoot: string
  readonly baseCommit: string

  readonly exitCode: number

export interface AntiCheatSuiteReport {
  readonly passed: boolean
  readonly timestamp: string
  readonly vectorResults: Readonly<Record<string, boolean>>
  readonly allViolations: readonly string[]

/** Evaluates all mechanical anti-cheat vectors across the worktree and test execution. */
export function evaluateAntiCheatSuite(
  request: AntiCheatSuiteRequest,
): Promise<AntiCheatSuiteReport>
