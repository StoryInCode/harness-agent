# 06.11 — Workspace Mutation Tracker and Freshness Observer

**Set:** 06-verification · **Queue:** 11 · **Depends on:** `06.01`, `06.02`, `06.03`
**Status:** todo
**Harness primitive:** event/hook plugin · **Package:** `@deepseek-ai/dsh-verification-observer`

## Summary

Passively observes tool execution results via the frozen `tools/result` event (`packages/core/tools/src/index.ts:189, 1656`) to maintain real-time workspace verification freshness. For filesystem mutations (`writeText`, `editText`, `patch`), updates `stateTable` with `lastEditAt` and `changedPaths`, dirtying verification freshness (`verification/state-dirtied`). For terminal commands (`bash`, `terminal`), evaluates command attributability (`06.03`) and classified kind (`test`, `typecheck`, `lint`, `build`), automatically recording valid runs into the evidence ledger.

## Behaviour

- **Given** an agent running `writeText` on `src/logic.ts` **When** `tools/result` emits **Then** `stateTable` updates `lastEditAt` and `verification/state-dirtied` fires.
- **Given** an agent edit touching only `README.md` **When** `tools/result` emits **Then** the path is recorded but code verification freshness remains uncompromised.
- **Given** an agent executing `npm test` via bash tool **When** `tools/result` emits **Then** output is parsed and an attributable `VerificationEvent` is appended to the ledger.
- **Given** an agent executing `npm test || true` **When** `tools/result` emits **Then** recording is rejected due to exit code masking (`INV-11`).
- **Given** a failing tool execution **When** `tools/result` emits **Then** error details are captured without erasing historical verified evidence.

## Harness fit

This is an `event/hook plugin` primitive owned by `@deepseek-ai/dsh-verification-observer`. It taps the existing Harness `tools/result` event in `ToolRuntime` (`packages/core/tools/src/index.ts:189, 1656`), enabling passive, non-intrusive tracking of all filesystem mutations and terminal executions without wrapping or monkey-patching individual tools.

  trackTerminalExecutions: z.boolean().default(true),

export function apply(ctx: Context, config: WorkspaceObserverConfig): void
