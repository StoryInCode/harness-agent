# 06.15 — Anti-Cheat AC-4: Masked Shell Operator and Suppressed Exit Checker

**Set:** 06-verification · **Queue:** 15 · **Depends on:** `06.01`, `06.03`

**Harness primitive:** workflow capability · **Package:** `@deepseek-ai/dsh-anti-cheat-masked-exit`

## Summary

Enforces mechanical anti-cheat vector AC-4 (`INV-11`), evaluating test command lines proposed or executed by workers to prevent suppressed failure exits. Bridges the attributable shell parser (`06.03`) into the verification gate pipeline. Analyzes command ASTs for compound conditional operators (`|| true`, `|| :`, `|| echo`), sequencing semicolons with exit overrides (`; exit 0`), unmonitored pipes (`|` without `pipefail`), subshell masks `(cmd) || true`, and background detachments (`&`). Rejects any masked command with violation `ANTI_CHEAT_MASKED_EXIT`.

## Behaviour

- **Given** an attributable command `pnpm vitest run` **When** `checkMaskedShellExit` evaluates **Then** it confirms attributable execution.
- **Given** a compound command `npm test || true` **When** evaluated **Then** it rejects with violation `ANTI_CHEAT_MASKED_EXIT`.
- **Given** an exit override command `pytest ; exit 0` **When** evaluated **Then** it rejects with violation `ANTI_CHEAT_MASKED_EXIT`.
- **Given** a subshell wrapper `(npm test) || echo ok` **When** evaluated **Then** it rejects with violation `ANTI_CHEAT_MASKED_EXIT`.
- **Given** an unmonitored pipeline `npm test | grep pass` without `pipefail` **When** evaluated **Then** it rejects with violation `ANTI_CHEAT_MASKED_EXIT`.
