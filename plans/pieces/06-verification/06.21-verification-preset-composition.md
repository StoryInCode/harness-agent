# 06.21 — Verification Host and Worker Preset Composition

**Set:** 06-verification · **Queue:** 21 · **Depends on:** `06.07`, `06.10`, `06.20`
**Status:** todo
**Harness primitive:** patch layer · **Package:** `@deepseek-ai/dsh-verification-presets`

## Summary

Composes the verification subsystem into the DeepSeek Harness runtime environment across the Host Plane and Agent Plane. Configures the host bundle via `packages/bundle/base/cordis.patch.yml` routing `verification: sqlite` to the shared backend and mounting `VerificationService` (`06.20`). Mounts agent plugins into `presets/hermes-worker/agent.cordis.yml` without isolate realms (PRESET-RULE 1 & 4), installing the monotonic test pinning guard (`06.07`) and turn-stopping verification interceptor (`06.10`) inside worker sessions.

## Behaviour

- **Given** the base host bundle **When** launched with `cordis.patch.yml` **Then** `storageDomain` configures the verification route and `VerificationService` registers on the host container.
- **Given** a worker subagent spawning in `hermes-worker` preset **When** initialized **Then** `guard-test-pinning` and `verification-stop` mount in the agent's scoped context.
- **Given** an implementer attempting to mutate pinned tests **When** running inside the worker preset **Then** the pinning guard vetoes the tool call.
- **Given** an implementer attempting to end a turn without running tests **When** running inside the worker preset **Then** the turn-stop hook steers the agent into another step.
- **Given** an orchestrator or test writer preset **When** spawning **Then** `guard-test-pinning` is not mounted, permitting BDD test creation.

## Harness fit

This is a `patch layer` primitive owned by `@deepseek-ai/dsh-verification-presets`. It adheres to PRESET-RULES 1, 4, 6, and 8 (`PRESET-RULES.md`). The host service provider mounts in `cordis.patch.yml` on the Host Plane, while scoped plugins mount in `presets/hermes-worker/agent.cordis.yml` on the Agent Plane without isolate realms, ensuring worker sessions resolve host services while remaining constrained by scoped guards.

## Contracts

```yaml
# packages/bundle/base/cordis.patch.yml (Host Plane Composition)
'@deepseek-ai/dsh-storage-domain':
  backend: sqlite
  routes:
    verification: sqlite

'@deepseek-ai/dsh-verification':
  maxEventsPerSessionRoot: 100
  maxEventAgeDays: 30
  maxOutputSummaryChars: 2000

# presets/hermes-worker/agent.cordis.yml (Agent Plane Scoped Guards)
- id: guard-test-pinning
  name: '@deepseek-ai/dsh-guard-test-pinning'
  config:
    protectedPathPatterns:
      - 'tests/**'
      - 'test/**'
      - 'spec/**'
      - '**/*.test.ts'
      - '**/*.spec.ts'
      - 'vitest.config.*'
      - 'tsconfig.json'
    enforceFilesystemChmod: true

- id: verification-stop
  name: '@deepseek-ai/dsh-verification-stop'
  config:
    enabled: true
    maxAttempts: 2
```
