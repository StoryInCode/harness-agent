# 05.15 — Tool Execution and Sovereign Path Classifier

## Summary

Classifies tool calls and shell invocations into resource-heavy workloads versus lightweight diagnostic commands, and enforces human file sovereignty (`INV-09`). It evaluates tool names against configured patterns, tokenizes compound shell commands via a POSIX tokenizer (`shlex`) to detect heavy build and test binaries, and exempts diagnostic inspection commands (`git status`, `ls`, `cat`). It inspects filesystem mutation tools and shell redirection/deletion commands against `protectedPaths` to veto any autonomous mutation targeting `SOUL.md`.

## Behaviour

- **Given** a tool execution matching `heavyToolPatterns` (`execute_code`, `browser_exec`, `subagent_*`) **When** classified **Then** `isHeavy` returns `true`.
- **Given** a `bash` or `terminal` command invoking a heavy binary (`vitest`, `tsc`, `cargo`, `npm test`) **When** tokenized **Then** `isHeavy` returns `true`.
- **Given** a shell command running diagnostic queries (`git status`, `ls -la`, `pwd`) **When** tokenized **Then** `isHeavy` returns `false`, exempting it from headroom vetoes.
- **Given** a filesystem tool (`writeText`, `editText`, `str_replace_editor`) targeting `SOUL.md` **When** inspected **Then** `isSoulMutation` returns `true`.
- **Given** a shell command modifying `SOUL.md` (`rm SOUL.md`, `echo > SOUL.md`, `sed -i ... SOUL.md`) **When** tokenized **Then** `isSoulMutation` returns `true`.
- **Given** a read-only command inspecting `SOUL.md` (`cat SOUL.md`, `grep -rn "pattern" SOUL.md`) **When** tokenized **Then** `isSoulMutation` returns `false`, permitting read-only inspection.

## Harness fit

This is a `workflow capability` primitive owned by `@deepseek-ai/dsh-guard-tool-classifier`. It encapsulates lexical analysis, shell tokenization, and path normalization without coupling to the Cordis container or tool runtime. Decoupling classification allows unit testing of compound shell pipelines (`;`, `&&`, `|`) and path normalization.

export interface ToolClassificationResult {
  readonly isHeavy: boolean
  readonly isSoulMutation: boolean
  readonly matchedBinary?: string | undefined
  readonly targetPath?: string | undefined
  readonly reason?: string | undefined
}

export interface ToolClassifierConfig {
  readonly heavyToolPatterns?: readonly string[] | undefined
  readonly heavyCommandNames?: readonly string[] | undefined
  readonly protectedPaths?: readonly string[] | undefined
  readonly mutationToolPatterns?: readonly string[] | undefined
}

export interface ToolExecutionClassifier {
  classify(toolName: string, args: Record<string, unknown>): ToolClassificationResult
  isPathProtected(filePath: string): boolean
  tokenizeShellCommand(command: string): readonly string[]
}
