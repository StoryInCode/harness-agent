# 05.08 — Multi-Tier Work Preservation Guard (INV-07)

**Set:** 05-worktree-guard · **Queue:** 8 · **Depends on:** 05.01, 05.02, 05.07
**Status:** todo
**Harness primitive:** workflow capability · **Package:** `@deepseek-ai/dsh-worktree-preservation`

## Summary

Enforces Invariant `INV-07` by strictly refusing to delete any worktree holding uncommitted, untracked, or unpushed work through an authoritative 5-tier verification ladder. It evaluates repository root safety, working tree cleanliness (`git status --porcelain`), unpushed commit reachability (`git log HEAD --not --remotes`), squash-merge patch equivalence via `git cherry` (backed by the memoized cache), and remote PR merge state (`gh pr list --state merged`). If upstream preservation cannot be conclusively proven, pruning is aborted and `worktree/preserved` is emitted.

## Behaviour

- **Given** a worktree path pointing to the repository root **When** preservation runs **Then** it refuses deletion with `is_main_checkout` and throws `WorktreeSafetyError`.
- **Given** untracked files or unstaged changes in a worktree **When** `isWorktreeDirty` evaluates **Then** it reports `isClean: false` with preserve reason `dirty_working_tree`.
- **Given** committed changes not yet pushed to remote **When** `hasUnpushedCommits` runs **Then** it identifies local-only commits and checks upstream merge equivalence.
- **Given** commits squash-merged into upstream with identical patch IDs **When** `isPatchEquivalentUpstream` checks `git cherry` **Then** it recognizes the merge, updates the cache, and reports `isMergedUpstream: true`.
- **Given** commits merged via GitHub PR rebase **When** `isBranchPrMerged` queries `gh pr list --state merged` **Then** it recognizes the landing and reports `isMergedUpstream: true`.
- **Given** unpushed commits with no upstream match **When** classification runs **Then** deletion is vetoed with preserve reason `unpushed_commits`.

## Harness fit

This is a `workflow capability` primitive owned by `@deepseek-ai/dsh-worktree-preservation`. It implements the multi-tier inspection ladder enforcing `INV-07`. Encapsulating preservation logic enables non-mutating classification queries (for supervisors, inventory listings, and dashboards) as well as pre-prune gating.

## Contracts

```typescript
export interface PreservationVerdict {
  readonly canPrune: boolean
  readonly isClean: boolean
  readonly isPushed: boolean
  readonly isMergedUpstream: boolean
  readonly reason?: WorktreePreserveReason | undefined
  readonly unpushedCommitCount: number
  readonly dirtyFileCount: number
}

export class WorktreeSafetyError extends Error {
  constructor(message: string) {
    super(message)
    this.name = 'WorktreeSafetyError'
  }
}

export interface WorktreePreservationGuard {
  evaluatePreservation(worktreePath: string, repoRoot: string, signal?: AbortSignal): Promise<PreservationVerdict>
  isWorktreeDirty(worktreePath: string, signal?: AbortSignal): Promise<{ isDirty: boolean; fileCount: number }>
  hasUnpushedCommits(worktreePath: string, signal?: AbortSignal): Promise<{ hasUnpushed: boolean; count: number }>
  isPatchEquivalentUpstream(worktreePath: string, upstreamRef?: string, signal?: AbortSignal): Promise<boolean>
  isBranchPrMerged(branchName: string, repoRoot: string, signal?: AbortSignal): Promise<boolean>
}
```
