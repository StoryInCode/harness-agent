# 05.17 — Monotonic Tool Execution Guard (INV-12 & INV-09)

**Set:** 05-worktree-guard · **Queue:** 17 · **Depends on:** 05.13, 05.15, 05.16
**Status:** todo
**Harness primitive:** event/hook plugin · **Package:** `@deepseek-ai/dsh-guard-tool-guard`

## Summary

Registers an owner-level monotonic tool execution guard via `ctx.tools.guard()` that evaluates synchronously inside `ToolRuntime.stagePreExecuteAndGuards` after `tools/pre-execute` and approval resolution. When a tool call arrives, it checks for `SOUL.md` mutations; if detected, it immediately vetoes execution (`INV-09`). If a heavy command or tool is detected and host memory is below absolute floor (1536 MiB) or headroom floor (3072 MiB), it immediately vetoes execution (`INV-12`). Because `ToolGuard` returns `string | undefined`, returning a string guarantees immediate denial with `isError: true` that no downstream waterfall listener can convert to permission.

## Behaviour

- **Given** an active tool guard **When** a tool executes **Then** it evaluates synchronously inside `stagePreExecuteAndGuards` before `tool.execute()`.
- **Given** a tool call attempting to mutate or delete `SOUL.md` **When** evaluated **Then** it returns an explicit `INV-09` denial string and emits `resource/soul-violation`.
- **Given** a heavy command when host available memory is < 1536 MiB **When** evaluated **Then** it returns an explicit `INV-12` floor breach denial string and emits `resource/admission-denied`.
- **Given** a heavy command when host memory headroom is < 3072 MiB **When** evaluated **Then** it returns an explicit `INV-12` headroom breach denial string and emits `resource/admission-denied`.
- **Given** a `tools/pre-execute` waterfall returning `{ kind: 'allow' }` **When** memory is constrained **Then** the monotonic guard still denies execution and skips `tool.execute()`.
- **Given** plugin disposal **When** unmounted **Then** the disposer returned from `ctx.tools.guard()` cleans up the hook via `ctx.effect()`.

## Harness fit

This is an `event/hook plugin` primitive owned by `@deepseek-ai/dsh-guard-tool-guard`. It registers on `ctx.tools.guard()` (`packages/core/tools/src/index.ts:1100-1106`) rather than `tools/pre-execute` waterfalls. Monotonic owner-level guards prevent downstream listeners or approval prompts from bypassing non-negotiable physical stability (`INV-12`) and security boundaries (`INV-09`).
