## Summary

Inspects systemd cgroup v2 metrics for the worker subagent slice (`hermes-work.slice`) under `/sys/fs/cgroup/`. It parses `memory.current`, `memory.max`, `memory.swap.current`, `memory.swap.max`, and `memory.oom.group`, evaluating RAM and swap consumption against configured aggregate slice ceilings (default 6 GiB RAM, 512 MiB swap). This component is Linux/systemd-specific: on non-Linux platforms, container environments without cgroup v2 delegation, or systems lacking systemd, it cleanly marks `cgroupAvailable: false` without throwing errors.

## Behaviour

- **Given** a Linux host with cgroups v2 mounted **When** `readSliceMetrics()` runs **Then** it parses current and maximum memory and swap usage for `hermes-work.slice`.
- **Given** a platform without cgroups (macOS, Windows) **When** `readSliceMetrics()` runs **Then** it returns `undefined` and marks `cgroupAvailable: false`.
- **Given** a Linux environment lacking systemd slice delegation **When** directory `/sys/fs/cgroup/hermes-work.slice` is missing **Then** it handles `ENOENT` gracefully, returning `undefined`.
- **Given** `memory.oom.group` exists in the slice directory **When** read **Then** it notes whether atomic group OOM termination is enabled.
- **Given** slice memory nearing the configured ceiling **When** metrics are evaluated **Then** it reports utilization percentage for throttling calculations.

## Harness fit

This is a `Service Provider` primitive owned by `@deepseek-ai/dsh-guard-cgroup-provider`. It isolates low-level Linux cgroup v2 filesystem parsing from general resource admission. Isolating cgroup logic ensures that host degradation on non-Linux or containerized systems operates seamlessly.

## Contracts

```typescript
export interface CgroupSliceMetrics {
  readonly sliceName: string
  readonly slicePath: string
  readonly memoryCurrentBytes: number
  readonly memoryMaxBytes: number
  readonly swapCurrentBytes: number
  readonly swapMaxBytes: number
  readonly oomGroupEnabled: boolean
  readonly readAt: number
}

export interface CgroupProviderConfig {
  readonly cgroupSlicePath?: string | undefined
  readonly sliceCeilingBytes?: number | undefined
  readonly swapCeilingBytes?: number | undefined
}

export interface CgroupProvider {
  readSliceMetrics(): Promise<CgroupSliceMetrics | undefined>
  isCgroupAvailable(): boolean
}
```
