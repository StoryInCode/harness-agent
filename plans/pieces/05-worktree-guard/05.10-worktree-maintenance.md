# 05.10 — Git Object Pack Sprawl Maintenance

**Set:** 05-worktree-guard · **Queue:** 10 · **Depends on:** 05.01, 05.02
**Status:** todo
**Harness primitive:** workflow capability · **Package:** `@deepseek-ai/dsh-worktree-maintenance`

## Summary

Maintains Git object database health and prevents filesystem performance degradation caused by pack file sprawl during intensive multi-worktree lifecycles. It monitors the count of `.pack` files under `<repoRoot>/.git/objects/pack/` against a configurable threshold (default 15). When exceeded, it triggers an asynchronous, fail-soft background `git repack -a -d --quiet` executed with low scheduling priority (`nice -n 19` on Linux) without blocking foreground agent turns.

## Behaviour

- **Given** a repository with pack count below `packSprawlThreshold` **When** pack health is evaluated **Then** it records health status and takes no repack action.
- **Given** pack file count reaching or exceeding threshold (>= 15) **When** pack health check runs **Then** it triggers a background repack task.
- **Given** a Linux host **When** background repack spawns **Then** it is executed under `nice -n 19` to preserve CPU headroom for active worker subagents.
- **Given** a failure during background repack **When** process exits non-zero **Then** it logs a diagnostic warning fail-soft without disrupting active worktrees.
- **Given** multiple allocation cycles triggering maintenance concurrently **When** a repack is already running **Then** duplicate requests are coalesced.

## Harness fit

This is a `workflow capability` primitive owned by `@deepseek-ai/dsh-worktree-maintenance`. It encapsulates background repository hygiene and scheduling. Separating maintenance from worktree creation guarantees that object repacking never slows down task dispatch or blocks subagent startup.

## Contracts

```typescript
export interface PackHealthReport {
  readonly packCount: number
  readonly threshold: number
  readonly isSprawling: boolean
  readonly isRepackRunning: boolean
  readonly lastRepackAt?: number | undefined
}

export interface PackMaintenanceConfig {
  readonly packSprawlThreshold?: number | undefined
  readonly minIntervalBetweenRepacksMs?: number | undefined
}

export interface PackMaintenanceManager {
  evaluatePackHealth(repoRoot: string): Promise<PackHealthReport>
  triggerMaintenanceIfNeeded(repoRoot: string): Promise<boolean>
  isMaintenanceActive(): boolean
}
```
