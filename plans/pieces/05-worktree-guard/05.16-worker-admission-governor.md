# 05.16 — Dynamic Worker Admission Governor

**Set:** 05-worktree-guard · **Queue:** 16 · **Depends on:** 05.13, 05.14
**Status:** todo
**Harness primitive:** workflow capability · **Package:** `@deepseek-ai/dsh-guard-admission`

## Summary

Evaluates host resource availability to decide whether to admit new worker subagents or heavy workloads, enforcing Invariant `INV-12 (Memory Headroom Floor)`. It checks that host available memory is at or above `minAvailableMemBytes` (default 1536 MiB) and that remaining headroom after active worker reservations (`activeWorkers * perWorkerReservationBytes`, default 768 MiB each) is at or above `headroomBytes` (default 3072 MiB). On Linux hosts with systemd cgroups, it also throttles admission if `hermes-work.slice` usage reaches `cgroupPressureThrottlePercent` (default 80%).

## Behaviour

- **Given** host memory below `minAvailableMemBytes` (1536 MiB) **When** `checkAdmission` evaluates **Then** it returns `admitted: false` with code `ABSOLUTE_FLOOR_BREACH`.
- **Given** host memory above floor but effective headroom after worker reservations below `headroomBytes` (3072 MiB) **When** `checkAdmission` evaluates **Then** it returns `admitted: false` with code `RESOURCE_ADMISSION_DENIED`.
- **Given** Linux cgroup slice usage exceeding `cgroupPressureThrottlePercent` (80%) **When** `canAdmitWorker` runs **Then** it returns `false`, preventing subagent dispatch.
- **Given** non-Linux or container execution without cgroups **When** admission runs **Then** it evaluates host memory headroom via `os.freemem()` without requiring cgroup metrics.
- **Given** ample host memory and unconstrained cgroups **When** admission runs **Then** it returns `admitted: true`.

## Harness fit

This is a `workflow capability` primitive owned by `@deepseek-ai/dsh-guard-admission`. It encapsulates admission arithmetic, reservation scaling, and pressure throttling. Providing a single mathematical engine guarantees that tool execution guards and Kanban dispatch governors make identical admission decisions.

## Contracts

```typescript
export interface AdmissionResult {
  readonly admitted: boolean
  readonly reason?: string | undefined
  readonly availableBytes: number
  readonly headroomBytes: number
  readonly reservedUnusedBytes: number
  readonly effectiveFreeBytes: number
  readonly code?: 'RESOURCE_ADMISSION_DENIED' | 'ABSOLUTE_FLOOR_BREACH' | 'SLICE_CEILING_BREACH' | undefined
}

export interface AdmissionGovernorConfig {
  readonly minAvailableMemBytes?: number | undefined
  readonly headroomBytes?: number | undefined
  readonly perWorkerReservationBytes?: number | undefined
  readonly cgroupPressureThrottlePercent?: number | undefined
}

export interface AdmissionGovernor {
  checkAdmission(requestedBytes?: number): Promise<AdmissionResult>
  canAdmitWorker(activeWorkerCount: number): Promise<boolean>
  calculateEffectiveHeadroom(activeWorkerCount: number): Promise<number>
}
```
