## Summary

Defines the abstract `WorktreeManager` service class extending `@deepseek-ai/cordis.Service` and merges `Context.worktrees` and typed events into Cordis. It establishes branded types (`WorktreeId`, `CommitSha`, `BranchName`) preventing primitive obsession and parameter transposition across Git operations. It provides domain records (`WorktreeRecord`, `WorktreeAllocateOptions`, `WorktreePruneOptions`, `WorktreeClassification`, `WorktreeInventoryEntry`, `WorktreeStatus`, `WorktreePreserveReason`) governing workspace allocation, classification, and pruning across the host plane.

### Human Decision Point: Option A vs Option B
- **Option A (Active)**: Declare an abstract `WorktreeManager` Cordis Service and branded types (`WorktreeId`, `CommitSha`, `BranchName`) to decouple consumers from concrete Git subprocesses and block string transposition at compile time.
- **Option B (Alternative)**: Export concrete Git subprocess execution functions using unbranded primitive strings directly, tightly coupling consumers to Git CLI details and risking silent argument confusion.

## Behaviour

- **Given** the Cordis root container **When** `@deepseek-ai/dsh-worktree` is loaded **Then** `ctx.worktrees` is recognized on `Context` as an instance of `WorktreeManager`.
- **Given** an arbitrary string containing path separators or whitespace **When** `asWorktreeId` is invoked **Then** it throws a descriptive `TypeError`.
- **Given** a 40-character hexadecimal string **When** `asCommitSha` is invoked **Then** it trims, lowercases, and returns a branded `CommitSha`.
- **Given** an active `WorktreeManager` **When** worktree lifecycle mutations occur **Then** typed events (`worktree/allocated`, `worktree/cleaned`, `worktree/preserved`, `worktree/locked`, `worktree/unlocked`) emit on the host bus.

## Harness fit

This is a `Service Definition` primitive owned by `@deepseek-ai/dsh-worktree`. It declares the abstract `WorktreeManager` interface and merges `interface Context { worktrees: WorktreeManager }` into Cordis (`packages/core/tools/src/index.ts:40-60`). Isolating contracts from provider implementations allows consumers like `@deepseek-ai/dsh-dev-loop-worktree` and `@deepseek-ai/dsh-kanban` to depend on types and signatures without importing concrete Git subprocess drivers.

## Contracts

```typescript
export type WorktreeId = string & { readonly __brand: unique symbol }
export type CommitSha = string & { readonly __brand: unique symbol }
export type BranchName = string & { readonly __brand: unique symbol }

export type WorktreeStatus = 'active' | 'clean' | 'dirty' | 'unpushed' | 'locked' | 'preserved'
export type WorktreePreserveReason = 'dirty_working_tree' | 'unpushed_commits' | 'active_live_lock' | 'non_git_directory' | 'is_main_checkout'

export interface WorktreeRecord {
  readonly id: WorktreeId
  readonly path: string
  readonly repoRoot: string
  readonly branch: BranchName
  readonly baseCommit: CommitSha
  readonly baseLabel: string
  readonly createdAt: number
  readonly lockedByPid?: number | undefined
  readonly lockReason?: string | undefined
}

export interface WorktreeAllocateOptions {
  readonly taskId: string
  readonly repoRoot?: string | undefined
  readonly branchName?: string | undefined
  readonly baseRef?: string | undefined
  readonly syncBase?: boolean | undefined
  readonly timeoutMs?: number | undefined
  readonly signal?: AbortSignal | undefined
}

export interface WorktreePruneOptions {
  readonly force?: boolean | undefined
  readonly timeoutMs?: number | undefined
  readonly signal?: AbortSignal | undefined
}

export interface WorktreeClassification {
  readonly path: string
  readonly status: WorktreeStatus
  readonly isClean: boolean
  readonly isPushed: boolean
  readonly isMergedUpstream: boolean
  readonly lockState: 'live' | 'dead' | 'unlocked'
  readonly preserveReason?: WorktreePreserveReason | undefined
}

export interface WorktreeInventoryEntry {
  readonly record: WorktreeRecord
  readonly classification: WorktreeClassification
  readonly diskSizeBytes?: number | undefined
}

export abstract class WorktreeManager extends Service {
  constructor(ctx: Context) { super(ctx, 'worktrees') }
  abstract allocate(options: WorktreeAllocateOptions): Promise<WorktreeRecord>
  abstract classify(worktreePath: string, signal?: AbortSignal): Promise<WorktreeClassification>
  abstract prune(worktreePath: string, options?: WorktreePruneOptions): Promise<boolean>
  abstract lock(worktreePath: string, reason: string): Promise<void>
  abstract unlock(worktreePath: string): Promise<void>
  abstract listWorktrees(repoRoot?: string, signal?: AbortSignal): Promise<readonly WorktreeInventoryEntry[]>
  abstract getWorktree(taskIdOrPath: string): Promise<WorktreeRecord | undefined>
}

declare module '@deepseek-ai/cordis' {
  interface Context { worktrees: WorktreeManager }
  interface Events {
    'worktree/allocated'(record: WorktreeRecord): void
    'worktree/cleaned'(worktreePath: string, branchName: string): void
    'worktree/preserved'(worktreePath: string, reason: string): void
    'worktree/locked'(worktreePath: string, pid: number, reason: string): void
    'worktree/unlocked'(worktreePath: string): void
  }
}
```

## Teach me while you build

Yo, super hacker Daru here. Let's talk about why you never, ever let bare strings loose in low-level git operations unless you want your filesystem nuked by a script-kiddie-tier typo!

- **What it does**: Establishes the abstract `WorktreeManager` service boundary and branded types for Git worktrees in Cordis.
- **Background**: Primitive obsession is when you pass raw `string` values for branch names, commit hashes, and file paths, letting TypeScript compile code where arguments are swapped.
- **How it works here**: In `packages/dev-loop/worktree/src/types.ts:1-40`, branded nominal types wrap raw primitives. The abstract class `WorktreeManager` in `packages/dev-loop/worktree/src/index.ts:1-42` injects `ctx.worktrees` without tying callers to raw child processes.
- **Why this approach**: Option A gives total compile-time isolation and mockability across the harness, whereas Option B leaks shell subprocess dependencies into every single consumer.
- **Approaches considered**: Raw unbranded strings (rejected: swapped commit SHA and branch name compiles silently) vs Runtime class wrapper objects (rejected: memory overhead and serialization bloat) vs Compile-time branded types (chosen).
- **Prior art inspected**: Git worktree porcelain specification (`git worktree --help`) and Cordis Service declaration merging in `packages/core/tools/src/index.ts:40-60`.
- **What we get for free**: Zero runtime memory penalty from TypeScript nominal branding, plus automatic Cordis dependency injection and lifecycle disposal.
- **What to notice**: Notice how `declare module '@deepseek-ai/cordis'` attaches `worktrees` directly to `Context`, making IDE autocompletion instant.
- **Concepts to own**: Nominal typing via type tagging / branding, preventing accidental parameter transposition at compile time.
- **Interview angle**: How do you prevent accidental parameter transposition in TypeScript without runtime overhead? Answer: Nominal branding via unique symbol tags.
- **Decisions you can now make alone**: You can add new worktree status enum tags without modifying the concrete Git subprocess runner.
- **Lesson**: Don't pass naked strings to Git commands; brand your IDs or prepare for catastrophic disk wiping!
