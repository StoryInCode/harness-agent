## Summary

Compiles minimal, focused continuation packets (`ContinuationPacket`) for interrupted, failed, or restarted worker sessions (Spec `M-010`). Extracts only unsatisfied axioms, recorded blockers, failed predicate results, and next recommended actions, projecting an ephemeral resumption state without bloating agent context with completed history. Enables seamless worker restarts and takeover without context explosion.

## Behaviour

- **Given** a card with 3 satisfied and 1 unsatisfied axiom **When** `compileContinuation` runs **Then** the packet contains only the single unsatisfied axiom.
- **Given** an unsatisfied axiom with a recorded blocker **When** compiled **Then** the blocker string and previous check failures are summarized in the packet.
- **Given** an active worker restart **When** injected **Then** the continuation packet provides immediate next action context.
- **Given** a card where all axioms are satisfied **When** compiled **Then** it returns an empty unsatisfied list and marks next action as completion.

## Harness fit

This component is a `session projection` compiling ephemeral worker resumption state from durable `ctx.storageDomain` records (`plans/04-axiom-verification-sweeper.md:30, 196-206`).

## Contracts

```typescript
import { Context, Service } from '@deepseek-ai/cordis'
import type { TaskAxiomId, TaskAxiomStatus } from '@deepseek-ai/dsh-axiom'

export interface ContinuationPacket {
  readonly taskId: string
  readonly compiledAt: string
  readonly unsatisfiedAxioms: readonly {
    readonly id: TaskAxiomId
    readonly statement: string
    readonly status: TaskAxiomStatus
    readonly blocker: string
  }[]
  readonly nextAction: string
}

declare module '@deepseek-ai/cordis' {
  interface Context {
    continuationCompiler: ContinuationCompiler
  }
}

export abstract class ContinuationCompiler extends Service {
  constructor(ctx: Context) {
    super(ctx, 'continuationCompiler', true)
  }
  abstract compileContinuation(taskId: string): Promise<ContinuationPacket>
}
```

## Teach me while you build

- **Background**: A session projection is an ephemeral, read-only data view compiled from durable records to give an agent exactly what it needs for its next turn without reloading raw history.
- **How it works here**: When a worker session resumes or restarts, the runner calls `ctx.continuationCompiler.compileContinuation(taskId)`. The compiler fetches stored axioms via `ctx.storageDomain`, filters out all satisfied axioms, collects blockers and failed sweep results from `ctx.axiomVerifier`, and computes a concise `nextAction` recommendation string. Open `packages/axiom/continuation/src/index.ts`.
- **Why this approach**: Focused delta projection. The simplest alternative is replaying the entire task transcript and card history, but that inflates context windows, wastes tokens, and confuses LLMs with obsolete intermediate failures.
- **What we get for free**: Cordis service isolation and typed access to `ctx.storageDomain` domain entities.
- **What to notice**: The packet is strictly ephemeral; it is never persisted back to storage, preventing projection drift from stale cached files.
- **Lesson**: Protect LLM context windows by projecting minimal actionable state deltas rather than replaying full lifecycle history.
