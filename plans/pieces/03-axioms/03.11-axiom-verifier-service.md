# 03.11 — Axiom Verifier Host Service and Anti-Self-Grading Sweeper

**Set:** 03-axioms · **Queue:** 11 · **Depends on:** 03.01, 03.03, 03.09, 03.10
**Status:** todo
**Harness primitive:** Service Provider · **Package:** `@deepseek-ai/dsh-axiom-verifier`

## Summary

Implements the `AxiomVerifier` host service on `ctx.axiomVerifier`, executing automated sweeps across card task axioms and colocated `AGENTS.md` checkable blocks. Actively enforces Invariant `INV-10` ("The worker reports, the sweeper decides"): if a worker claims an axiom is `SATISFIED` but its predicate check fails or cannot reproduce on disk, the sweeper resets status to `ACTIVE` with an attributable blocker. Emits `axioms/verified` on the host bus and syncs state to `ctx.storageDomain`.

## Behaviour

- **Given** a card with task axioms **When** `verifyTask(taskId)` executes **Then** it evaluates all predicate checks and returns a typed `TaskVerificationSummary`.
- **Given** an axiom claimed `SATISFIED` by a worker whose tests fail **When** swept **Then** status reverts to `ACTIVE` with `selfGradingReverted: true` (`INV-10`).
- **Given** an axiom with passing checks and attached proof **When** swept **Then** status updates to `SATISFIED`.
- **Given** touched paths in a workspace **When** `verifyCheckableAxioms` runs **Then** all governing `CheckableAxiom` blocks are evaluated.
- **Given** an unproven task **When** `assertTaskProven(taskId)` is called **Then** it throws `UnprovenDoneError` if any axiom remains unsatisfied.

## Teach me while you build

- **Background**: Self-grading is an anti-pattern where the worker that implements the code also certifies that its own implementation is correct without external verification.
- **How it works here**: `AxiomVerifier` mounts on `ctx.axiomVerifier`. When `verifyTask(taskId)` executes, it loads the task's axioms from `ctx.taskAxiomStore` and runs their predicate checks via `ctx.predicateEvaluator` and `ctx.attributableShell`. If a worker marked an axiom `SATISFIED` but the check fails on disk, the sweeper reverts it to `ACTIVE` with a blocker reason (`INV-10`). It emits `axioms/verified`. Open `packages/axiom/verifier/src/index.ts`.
- **Why this approach**: Independent host-plane sweeper. The simplest alternative is trusting worker status updates, but workers hallucinate test results; an independent sweeper ensures ground truth decides state.
- **What we get for free**: Composes `predicateEvaluator` and `attributableShell` on the host plane, keeping verifier logic clean and focused on aggregation.
- **What to notice**: `assertTaskProven(taskId)` throws `UnprovenDoneError` if any axiom remains unsatisfied, providing the core assertion used by completion gates.
- **Lesson**: The worker reports, the sweeper decides: never allow an agent to grade its own work without an independent verification pass against real disk state.
