## Summary

Detects contradictory constraints across ancestor and descendant `AGENTS.md` files within the repository directory hierarchy (`checkHierarchyConsistency`). Performs core token extraction, negation detection, and pairwise predicate comparison to flag direct polarity inversions (e.g. parent prohibits `RS256` via `grep_absent`, child mandates `RS256` via `required_symbol`) unless the child explicitly declares an `overrides: <id>` exception. Emits `axioms/conflict-detected` on the host bus to alert operators.

## Behaviour

- **Given** an ancestor `AGENTS.md` forbidding `eval` and a child `AGENTS.md` requiring `eval` without an override **When** consistency check runs **Then** it returns `valid: false` with conflict details.
- **Given** a child `AGENTS.md` specifying an explicit `overrides: SIC-SEC-001` **When** consistency check runs **Then** the contradictory predicate is allowed and `valid: true` is returned.
- **Given** consistent parent and child constraints across all packages **When** checked **Then** it returns `valid: true` and zero conflicts.
- **Given** an unhandled polarity contradiction **When** discovered during repository crawl **Then** `axioms/conflict-detected` is emitted on the host bus.

## Teach me while you build

- **Background**: Scope contradiction happens when a parent directory specifies one rule (e.g. root forbids `eval`) and a child directory specifies the opposite (e.g. compiler module requires `eval`), creating an unsolvable verification failure unless explicit overrides are declared.
- **How it works here**: `checkHierarchyConsistency(projectRoot)` crawls all `AGENTS.md` files in the tree. For each ancestor-descendant pair, `detectContradiction` compares predicate types and targets (e.g. `grep_absent` vs `required_symbol` on the same pattern). If contradictory and the child lacks `overrides: <parent-id>`, it flags a conflict and emits `axioms/conflict-detected`. Open `packages/axiom/consistency/src/index.ts`.
- **Why this approach**: Pairwise predicate polarity analysis with explicit overrides. The simplest alternative is letting descendant rules silently overwrite ancestor rules, but silent overwrites mask accidental rule violations in deep directories.
- **What we get for free**: `ctx.emit('axioms/conflict-detected')` notifies host monitors and UI surfaces without tightly binding them.
- **What to notice**: Explicit `overrides: <id>` allows legitimate local exceptions (like test fixtures needing mock tools) while logging audit intent.
- **Lesson**: Allow child scopes to specialize or override parent rules, but require explicit opt-in so unintentional contradictions fail fast.
